# banto

人に伴走し、人の助けとなるソフトウェア。第一の領域はソフトウェア開発。

Vibe Coding で平行開発をすると、人の側が破綻する。複数プロジェクトを同時に持つことも、
1つのプロジェクトで複数の作業を走らせることも、生産性のためにやるのに、どちらも
「いま何がどこまで進んでいるか」を人の頭に積み上げていく。

**banto の目的は平行開発そのものではなく、平行開発をしても人の認知負荷が上がらないようにすること。**

- `docs/vision.md` — 何のためのものか
- `docs/requirements.md` — 要件
- `docs/adr/adr-0001-architecture.md` — アーキテクチャ
- `docs/lessons.md` — 前の実装で払った授業料
