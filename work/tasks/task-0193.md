## 何が起きているか（今日の実測。数字が優先度を語る）

**ゲートのスコープ重複判定が粗すぎて、工場が事実上1本ずつしか動いていない。**

- **17本が2時間以上直列化した**（imp-0071）。先頭の task-0159 が `packages/**` を押さえていたため、
  OOM の直し（task-0165）や記録の欠落の直し（task-0164）まで全部その後ろで止まった。
  **`packages/**` と書いたのは番頭自身の失敗**だが、それだけでは説明が付かないことが後で分かった。
- **片側を名指しまで絞っても、待ちは 15本 → 10本にしかならなかった**（task-0192。
  スコープは `pi-rpc-driver.ts` / `claude-agent-driver.ts` / `child-stdin-epipe.spec.ts` の3ファイルだけ）。
  **相手側が `tests/acceptance/**` を持っている限り、こちらがどれだけ狭めても塞がれる。**
- 結果として **`max_concurrent_sessions: 5` が効いていない**。**実効の同時実行数は1本**。
  **試験を1本でも置く契約は、互いに必ず重なる**からである。

**積み方の作法（狭く名指しする）で解くのは諦めた**——①書き手全員が完璧に名指しし続けない限り効かない
②**着手後は狭められない**（既に触った差分がスコープ外になり、マージ前ゲートで落ちる。imp-0071 の追記）。
**唯一の機会である「積む瞬間」に賭ける設計は、外れたときの代償が大きすぎる。**

## どこが穴か（読んで確認済み）

`packages/banto-daemon/src/gate-evaluator.ts:126` の `globPrefix` が、
**最初のワイルドカードを含む「セグメント」単位で literal を切っている**：

```ts
const segments = p.split("/");
const wildcardIdx = segments.findIndex((seg) => seg.includes("*"));
...
return segments.slice(0, wildcardIdx).join("/") + "/";
```

つまり `tests/acceptance/backlog-*.spec.ts` の前置詞は **`tests/acceptance/`** になる。
`backlog-` の部分が捨てられるので、`tests/acceptance/` 配下の**あらゆるもの**と重なると判定される。

`globsOverlap`（:165）自体は「前置詞のどちらかが他方の前置詞で始まるなら重なる」という保守的な判定で、
**考え方は正しい**（コメントにも「Returns false ONLY when we can prove they are disjoint」と書いてある）。
**壊れているのは前置詞の取り方だけ**である。

## 何をするか

**`globPrefix` を「文字単位で切る」形に直す**——`*` の**直前まで** literal を取る。

```
tests/acceptance/backlog-*.spec.ts  → "tests/acceptance/backlog-"   （いまは "tests/acceptance/"）
tests/acceptance/**                 → "tests/acceptance/"           （変わらない）
packages/**                         → "packages/"                   （変わらない）
src/*/a.ts                          → "src/"                        （変わらない）
*                                   → ""                            （変わらない）
tests/acceptance/foo.spec.ts        → 完全パス（ワイルドカード無し。変わらない）
```

これだけで、**`tests/acceptance/child-stdin-epipe.spec.ts` と `tests/acceptance/backlog-*.spec.ts` のような
「証明可能に交わらない組」が解ける**。`globsOverlap` の側は触らなくてよいはず——
**触る必要があると判断したら、その理由を報告に書くこと。**

### **過保護を無くしきる必要はない**（ここを間違えないこと）

目的は「**証明可能に交わらないものだけ解く**」ことであって、判定を正確にすることではない。

> **塞ぎ漏らすと、同じファイルを2人が同時に触る。迷ったら塞ぐ側に倒す。**

この方針を **`globsOverlap` / `globPrefix` の冒頭コメントに明記すること**（受け入れ条件 a2）。
既存のコメント「This is intentionally over-conservative ... false parallel is better than
false independence」は正しいので、**消さずに残し、なぜ前置詞の取り方だけ精密にしたのかを足す**。
