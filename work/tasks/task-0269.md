## 背景
task-0267 が claude-quota.spec.ts の「決定98a」自己完結化に取り組む過程で、フルスイート負荷下の検証コンテナでのみ間欠的に落ちる claude-agent-start-timeout.spec.ts の a2/a4 の欠陥を発見・修正した（task-0267 の 93529a49）。これは claude-quota とは無関係の既存欠陥で、task-0267 のスコープ（tests/acceptance/claude-quota.spec.ts 等）から外れているため、切り離してこのタスクで扱う。

## 修正内容（93529a49 を再現）
- a2/a4 が BANTO_CLAUDE_START_TIMEOUT_MS=150ms を強制し、負荷下では素の node サブプロセスの bootstrap が 150ms を超えて2回目の起動（成功必須）が間に合わない。
- このテストだけが素の bootstrap を待つ必要があることを根拠に、BANTO_CLAUDE_START_TIMEOUT_MS を 150ms → 1000ms へ上げる（既定10s より十分短い。失敗専用ブロック a3/a5 は 150ms のまま）。
- 変更ファイル: tests/acceptance/claude-agent-start-timeout.spec.ts のみ。
