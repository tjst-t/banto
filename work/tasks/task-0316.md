## 背景（あなたは記憶を持たないので全部ここに書きます）

番頭（banto）は systemd の常駐サービスで動いていて、`deploy/banto.service:56` に `Environment=BANTO_BROWSER_ALLOW_NO_SANDBOX=1` が入っています。計画的デプロイ（`system.deploy`）は、起こし直す直前に**その稼働中のプロセスの子として** `npm test` を回します。したがってデプロイ検証のときだけ、試験は `BANTO_BROWSER_ALLOW_NO_SANDBOX=1` が立った世界で走ります。いっぽうマージ前ゲートの検証コンテナ（docker/test.yaml）には BANTO_* が1つも無いので、ゲートでは緑のままです。

そのせいで 2026-08-20 のデプロイ検証（tests 2900）で次が落ちました。

```
✖ BANTO_BROWSER_ALLOW_NO_SANDBOX が無ければ --no-sandbox は入らず、status も enabled
  AssertionError: 既定なのに --no-sandbox が入っている
  tests/acceptance/browser-chromium-launcher.spec.ts:673（actual false / expected true）
```

docker で対照実験済みです：**変数なしで 43/43 合格、`BANTO_BROWSER_ALLOW_NO_SANDBOX=1` を与えると 42/43 が落ちる**。

### 因果

実装（`packages/banto-host/src/browser/chromium-launcher.ts:505-507`）はこう書かれています。

```ts
const allowNoSandboxEnv =
  options.allowNoSandboxEnv ?? process.env["BANTO_BROWSER_ALLOW_NO_SANDBOX"];
const sandboxDisabled = allowNoSandboxEnv === "1";
```

試験（`tests/acceptance/browser-chromium-launcher.spec.ts:669`）は「環境変数は無い」つもりで `allowNoSandboxEnv: undefined` を渡していますが、`??` は `undefined` を「未指定」と読むので**右辺の実環境変数へ落ちます**。他の試験は `allowNoSandboxEnv` を渡していないので、同じく実環境変数を見にいきます。

## どちらを直すか（採った案とその理由）

**試験側を直します。実装（`chromium-launcher.ts`）には手を入れないでください。**

理由：「未指定なら実環境変数を見る」のは本番の仕様として正しい動きです（サービスの Environment でサンドボックス無効化を許すのがこの変数の役目）。欠けているのは、「環境変数が無い世界」を主張する試験が**その世界を自分で作っていない**ことのほうです。試験が前提を自分で組み立てれば、どの環境で走らせても同じ結果になります（実装の分岐を増やさずに済み、同じ形の罠を持つ他の試験にも同じ型が使えます）。

## やってほしいこと

`tests/acceptance/browser-chromium-launcher.spec.ts` だけを直します。

1. **ファイル全体で実環境変数を遮断する。** `before`（または各 describe の先頭）で `process.env["BANTO_BROWSER_ALLOW_NO_SANDBOX"]` を退避して `delete` し、`after` で**元に戻す**（元が無ければ削除したまま）。他の spec へ漏らさないこと。
2. **「無い」ことを明示的に渡す。** 664 行の試験は `allowNoSandboxEnv: undefined` ではなく、環境変数へ落ちない値（空文字 `""` など。`??` は `undefined`/`null` のときだけ右辺へ落ちるので `""` は素通りしません）を渡し、「未指定だから実環境を見る」経路に依存しないようにすること。680 行の試験は従来どおり `"1"` を明示で渡す。
3. 変更は試験ファイルの中だけに収めること。実装・他の spec は触らない。

## 確かめ方（ここが要件です）

**`BANTO_BROWSER_ALLOW_NO_SANDBOX=1` を立てた状態でも全部通ること**を機械で確かめます。今回の対照実験がそのまま基準です。変数を立てた実行と、立てない実行の**両方**で通ること。
