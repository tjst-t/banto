## 背景

PO から「banto が異様に Token を食う」と指摘があり、本番の記録（`threads/*.jsonl` 218本・LLM リクエスト 29,337回）を集計した。送信入力の推定合計 71.8億字のうち、**76.3% が「履歴の再送」**（残り 23.7% が毎ターンの固定費）。つまり**会話が伸びること自体が最大の費用**である。

その伸びを抑えるはずの仕組みが「章を畳んで引き継ぐ」なのだが、実測はこうだった：

- **218本のうち 184本が、章を一度も畳んでいない**
- `thread-50` は稼働中のまま**文脈 1,086,086字 ≒ 約40万トークン、1,803リクエスト無畳み**
- 畳んでいる `thread-61` でも、発火は **48〜63万字**に達してから

原因は `packages/banto-host/src/chapters.ts` の `shouldClose()`（275行目付近）：

```ts
shouldClose(): boolean {
  const window = this.contextWindow();
  const ratio = this.options.thresholdRatio ?? DEFAULT_CHAPTER_THRESHOLD_RATIO;
  if (!window || window <= 0) {
    return this.evaluate({ tokens: undefined, window, thresholdRatio: ratio, willClose: false });
  }
  ...
  const tokens = this.contextTokens();
  if (tokens === undefined) {
    return this.evaluate({ tokens: undefined, window, thresholdRatio: ratio, willClose: false });
  }
  return this.evaluate({ ..., willClose: tokens >= window * ratio });
}
```

`contextWindow()` は `this.harness.contextWindow?.() ?? this.options.contextWindow`。**ハーネスが窓を報告しないプロバイダで、かつ `options.contextWindow` も無いと、`willClose` は永久に false になる**。同じく、ハーネスがトークン数を報告しないと `contextTokens()` が undefined になり、やはり永久に畳まれない。

**「窓が分からない」は「畳まなくてよい」ではない。**いまは分からないほど安全側に倒れているが、実際には分からないときほど無制限に伸びている。

## やること

**窓やトークン数が引けないときの保険を入れる。**判定の本筋（窓もトークン数も引けるときの `tokens >= window * ratio`）は**一切変えないこと**。

1. **窓が引けないときの既定値**を用意する。`options.contextWindow` も harness も答えないときに使う保守的な既定を定数として置き、そこから判定できるようにする。値は既存の設定・モデル情報から引ければそれを使い、無ければ定数で構わない。**値の根拠をコードのコメントに残すこと。**
2. **トークン数が引けないときの保険**として、字数からの概算で判定できるようにする。換算の目安は本番記録の実測で **2.71字/トークン**（CJK 比率 28.6%、日本語1.5字/トークン・英数4.0字/トークンの目安による概算）。**概算であることをコメントに明記**し、概算で判定したことが `evaluate()` の記録に残るようにすること（あとから「何で判定したか」を辿れるようにする）。
3. 保険で畳んだ場合も、**畳んだあとの引き継ぎ（handoff）の作り方は既存と同じ**であること。畳み方そのものは変えない。
4. `minMessages` の下限チェックは残すこと（短い会話を畳まない）。

## 気をつけること

- **畳みすぎは畳まなすぎより悪い。** 保険の既定値は、正しい窓が引けているときの挙動を変えない範囲で保守的に置くこと。既存の会話が急に頻繁に畳まれ始めないよう、既定値は大きめ（＝畳みにくい側）に取る。
- `evaluate()` を判定の唯一の出口にしている設計（a1）を壊さないこと。**どの分岐から返るときも `evaluate()` を通す。**
- 稼働中の会話の記録を壊す変更をしないこと（記録形式は変えない）。
