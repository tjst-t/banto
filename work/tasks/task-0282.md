## 背景
banto のチャット UI で、AI の思考（Thinking / reasoning）の内容がリアルタイムで**展開表示されるのがデフォルト**になっている。見ようと思って見られるのは良いが、ユーザが**クリックして開かない限りは、Thinking の部分は閉じた（折りたたんだ）状態**にしたい。PO 指示 2026-08-19「見ようとして見れるのはいいのですが、ユーザがクリックして開かない限りは、Thinkingのところは閉じておくように修正」。

## やること
- チャットに表示される Thinking（思考・reasoning）ブロックを、**デフォルトで折りたたみ（閉じた状態）**にする
- ユーザがクリック（または開く操作）すると展開して中身が見えるようにする（展開機能は残す）
- **返信中に表示されるリアルタイムの思考表示も同様に、デフォルトでは閉じておく**
- 既存の見た目・操作を壊さない

## 対象ファイルの目星（実装時にコードを読んで確認すること）
- packages/banto-web/src/Room.tsx — チャット表示の本体。ThinkingRow（81行付近・返信中の思考表示）と、メッセージ内の reasoning ブロックの描画
- packages/banto-web/src/useBantoSession.ts — reasoning_delta / reasoning_end イベントで role: "reasoning" のメッセージを積む箇所（241〜252行付近）

## 実装の進め方
1. チャットのメッセージ一覧で、role が reasoning / thinking のブロックがどう描画されているか、Room.tsx と関連コンポーネントを読んで特定する
2. そのブロックに「デフォルトで閉じた折りたたみ」を実装する（折りたたみ表示・クリックで展開）。UI コンポーネントの spec（banto-web にテスト文化があれば）を追加・更新し、デフォルトで閉じていること・クリックで開くことを確かめる
3. 返信中のリアルタイム思考表示（ThinkingRow）もデフォルトで閉じた状態にする

## 注意
- 変更は banto-web（チャット UI）の範囲に留める
- ユーザが「開く」手段を失わせない（閉じっぱなしにしない）
- npm run typecheck と npm test が通ること

## 完了条件
- Thinking ブロックがデフォルトで折りたたまれて表示される
- クリックで展開して中身が見える
