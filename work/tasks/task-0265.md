監査ロール（auditor）に、道具呼び出し（audit_report 等）が実証されていないモデルを当てられないようにする（再発防止）。

# 背景
- task-0246 / 0242 の監査が「監査人が判定の口（audit_report）を使わずに報告」で failed した。実際には roleAssignments が3ロールとも huihui/deepseek-v4-flash-abliterated に固定され、そのモデルが道具呼び出しに乗れていなかった（エラー文言「ランタイムに監査の口が載っていません」は誤り）
- 監査の役に道具呼び出し未実証のモデルを当てると、監査人が判定を出せず誤診・誤った failed が起きる

# やり方
- roleAssignments で監査ロールにモデルを当てるとき、そのモデルが道具呼び出し（audit_report）に対応しているかを検証する
- 対応が実証されていないモデルを当てようとしたら、起こす前に弾く・警告する（当てるなら明示的に許可する形）

# 完了条件
上記 acceptance を満たすこと。
