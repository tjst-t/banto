## 背景（前提を書き切る・職人は記憶を持たない）

取次（inbox）の面に並ぶ札には「この件の会話へ」という導線がある（`packages/banto-web/src/Inbox.tsx:244` の `openLabel`）。押すと**その件の会話が開く**のが約束（面の説明文にも「押すと、その件の会話と面が同時に開きます」と書いてある）。

**ところが実際には会話が移らない。**面が閉じて、**いま見ていた会話のまま**戻るだけになっている。PO からは「違う会話が開く」と報告されている。

## 原因（番頭がコードを読んで特定済み。ここから始めてよい）

二段構えで、**どちらも「移れ」と言っていない**。

1. **画面側** `packages/banto-web/src/App.tsx:302` `openInboxItem`
   - `session.openInbox(itemId)`（＝ホストへ `inbox_open` を投げる）を呼んだあと、
     `item.opens?.settings` があるときだけ `navigate({face:"settings"})` する。
   - **それ以外は `backToChat()` するだけ**。`backToChat` は `prev.threadId` をそのまま持ち越すので、**いま見ている会話のまま面を閉じる**。
   - すぐ上の行（`App.tsx:270`）に `openThread(threadId, {focus})` があり、これが「会話を移る」正しい口（`session.switchThread` を呼ぶ）。**`openInboxItem` はこれを呼んでいない。**
   - `openInboxItem` の docstring にある「**会話と面はホストが動かす**。画面が受け持つのは『どの面を出すか』だけ」は**事実に反する**（下記2）。この誤ったコメントも直すこと。

2. **ホスト側** `packages/banto-host/src/server.ts:1938` `handleInbox`
   - `inbox_open` のときは `item.opens.threadId` の会話を引いて**その会話のキャンバスを開くだけ**で `return` する（`server.ts:1969`）。
   - **クライアントへ「この会話へ移れ」を送る口がプロトコルに無い**（`protocol.ts` にその型は無い）。つまりホストは画面の会話を動かせない。

**したがって直しは画面側で完結させる**（ホストのプロトコルに新しい型を足す必要は無い。足さないこと——スコープ外）。

## やること

`packages/banto-web/src/App.tsx` の `openInboxItem` を、押した札が指す会話へ実際に移るようにする。

- `item.opens?.threadId` があるなら、その会話へ移る＝ `openThread(item.opens.threadId)` を使う（`backToChat` を内包しているので二重に呼ばない）。
- `opens.settings` があるときの今の挙動（設定の面へ移り、`section` を渡す）は**変えない**。会話と設定の両方が指定されている札（テストの `GRANT_ITEM` がそれ）では、**会話へ移ったうえで設定の面を出す**——両方指定されているものを片方だけ効かせない。
- **指す会話が既に畳まれている**とき（`session.threadOf()` で開いている幹・枝に見つからず、`session.closedThreads` に在る）は、**開き直さない**。`App.tsx:288` の `readThread(threadId)` と同じ扱い＝履歴の面でその会話を読む形にする。理由は `readThread` の docstring にある PO 裁定「確認しに行っただけで開き直るのは事故」。
- **指す会話がどこにも無い**ときは、いまの挙動（`backToChat()`）のままでよい。黙って何も起きないのではなく、少なくとも面は閉じる。
- 会話の横に出る `PendingDecisions`（`Inbox.tsx` 下部・`variant="chat"`）の挙動は**変えない**——その会話宛の札には導線を出さない（`openLabel(item, here)` の `here`）。ここは既に正しい。

## やらないこと（スコープ）

- 「確認するだけの知らせをまとめて閉じる」ボタンは**別のタスク**。この枝でもう1本積むので、ここでは触らない。
- 取次の面の見た目・並び・文言は変えない（誤ったコメントの訂正を除く）。
