## 背景

task-0228 の着地後、番頭が main（3ec9ecbc）で `npm test` を袋の外から回したところ、
**受け入れ試験が3件落ちている**。落ちているのは task-0228 とは無関係で、記録の採番の重複が原因：

```
✖ [AC-T0152-1] 記録の id は一意（work/inbox・docs/adr）
✖ [a1] ファイル名の id が重複していない
✖ [a1] frontmatter の `id:` が重複していない
  imp-0070: work/inbox/improvement/imp-0070-branch-conclusion-cannot-hand-work-to-the-trunk.md
          / work/inbox/improvement/imp-0070-po-answer-cannot-reach-amend.md
```

同じ `imp-0070` を名乗る改善票が2本ある（ファイル名・frontmatter の両方）。
`npm run typecheck` は通っており、落ちているのはこの重複だけ。**main が赤いまま**なので早く消したい。

## やること

1. `git log --diff-filter=A -- <各ファイル>` で**どちらが後から入ったか**を確かめる。
   後から入った方を付け替える（先にあった方の id は動かさない）。
2. 付け替え先は **work/inbox 全体で未使用の、いちばん小さい imp 番号**（既存の最大＋1でよい。
   `work/inbox/improvement/` を一覧して決めること）。
3. 付け替えるのは**ファイル名と frontmatter の `id:` の両方**。
   さらに `work/` 配下・`docs/` 配下から**その改善票を参照している箇所**（`imp-0070` の文字列）を
   grep し、付け替えた側を指している参照だけを新しい番号へ直す。
   もう一方（残す側）を指している参照は触らないこと——**どちらを指しているかは前後の文脈で読む**。
4. 中身（本文）は書き換えない。採番の付け替えだけ。

## やらないこと

- コードには一切触らない（変更してよいのは `work/inbox/improvement/**` と、参照を直す `work/**` `docs/**` の md だけ）。
- 他の記録の採番を整理し直さない。
