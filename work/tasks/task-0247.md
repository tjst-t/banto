# 依頼

Worker Pool の並行制御を「想定消費リソース」ベースに変える設計（work/reports/2026-08-17-worker-resource-based-concurrency.md・accepted）のタスク A。

`packages/banto-worker-pool/src/host-resources.ts` を新規作成し、ホストの空きリソースを計測する。

- メモリ: `/proc/meminfo` の `MemAvailable`（kB）を読む。無ければ `os.freemem()`
- CPU（第2段の準備）: `os.cpus().length` からコア数、`/proc/loadavg` の 1 分平均から空きコア数を推定（`idleCores = max(0, cpuCount - loadAvg1)`）
- 計測は軽い /proc 読みなので、起動判定のたびに呼んでよい

設計書の「2. ホスト空きリソースの計測」を参照。
