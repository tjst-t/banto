## 背景・目的

チャット UI の「Thinking（推論）表示」は、今は **考えている間（ストリーミング中）は開いて**表示する。PO はこれを「**考えている間も最初から畳んでおきたい**」と望んでいる（進捗は見えなくてもよい。本文の読みやすさを優先）。完了済みターンが既に既定で閉じているのは現状どおり維持する。

## 現状（実装済みの折りたたみ機構）

- 描画は `packages/banto-web/src/messages.tsx` の `ReasoningRow`（213〜258行）。`ChatRow` の `entry.role === "reasoning"` 分岐（messages.tsx:446-457）から呼ばれる。
- `defaultOpen` の計算（messages.tsx:453-455）:
  ```
  isStreaming={isStreaming === true && entry.durationMs === undefined}
  defaultOpen={isStreaming === true || entry.durationMs === undefined}
  ```
  → 「考えている間（isStreaming && durationMs 未確定）= **開く**」「完了ターン = **既定で閉じる**」。
- 自動クローズ: 一度も触らず・未クローズなら、終了 `REASONING_AUTO_CLOSE_MS`（=1000）後に強制クローズ（messages.tsx:227-236）。
- 見出し `.reasoning-head`（ボタン・開閉トグル、messages.tsx:241-246）に、考え中は `.shimmer`「考えています」、終了後は thoughtLabel「X秒間考えました」を表示。キャレット `.reasoning-caret` は開=chevron-down / 閉=chevron-right。
- 職人出力（`views/WorkerViewer.tsx:445`）は既に `defaultOpen={false}`。

## 変更内容

1. `messages.tsx:446-457` の `case "reasoning"` で、`defaultOpen` を**ストリーミング中でも false（閉じる）**になるよう変える。つまり Thinking 本文（`.reasoning-body`）は、考えている間も・完了後も・履歴でも、**常に既定で閉じている**こと。
   - 見出し（`.reasoning-head`）は常に見えるまま。考え中は「考えています」（shimmer）、終了後は「X秒間考えました」を表示し続ける（削らない）。
   - 手動トグル（見出しを押すと開く／もう一度押すと閉じる）は従来どおり効くこと。
2. 自動クローズの扱いを整理する。既定で閉じ始めるため、従来の「終了1秒後に強制クローズ」は不要になりうる。ユーザーが開けた場合は `touched` で自動クローズは元々効かない。不要なら `REASONING_AUTO_CLOSE_MS` の自動クローズ処理と定数を削除してよいが、挙動（手動で開いたら開いたまま）は保つこと。
3. `tests/chat-ux.spec.ts` の「思考の表示（AI Elements の Reasoning）」テスト一式（1024〜1126行付近）を新しい既定に合わせて更新する:
   - テスト「考えている間は開いて出し、終わったら1秒ほどで畳む」（1025-1040）: 考え中に `.reasoning-body` が**可視**だとassertしている部分（1028-1031）を「**.reasoning-body が既定で非表示**」に書き換える。見出し `.shimmer`＝「考えています」は引き続き可視。また終了後の「1秒後に畳む」自動クローズのassert（1037-1039）は、既定が閉じたので不要になるなら整理する。
   - 「思考も差分が届くたびに伸びる」（1098-1105）: 本文を読むには開く操作を先に入れる必要があれば先に `.reasoning-head` を開いてから差分を検証するよう直す。
   - 「考え終わった時間も、その場で出る」（1118-1125）: 見出しの時間表示はそのまま検証可能。本文の可視を前提にしているなら開く操作を足す。
   - 必要なら「考えている間も既定で閉じている」ことを明示する新しい検証を足してよい。

## 完了条件

- 考えている間も Thinking 本文（`.reasoning-body`）が既定で閉じている。
- 見出し `.reasoning-head`・「考えています／X秒間考えました」の表示は残る。
- 見出しを押すと開き、もう一度押すと閉じる（手動トグル）。
- 完了済み履歴はこれまでどおり既定で閉じている。
