## 背景（これがすべての前提。読んでから始めること）

稼働機の `/etc/systemd/system/banto.service` は `Restart=always`、リポジトリの
`deploy/banto.service` は `Restart=on-failure` で食い違っている（inc-0072）。

**`system.restart` は `exit(0)`（正常終了）で終わる。** `Restart=on-failure` は正常終了では
起動し直さないので、**リポジトリの内容をそのまま稼働機へ入れると、`system.restart` を撃った
瞬間に banto が上がってこなくなる**。実装は `packages/banto-host/src/restart-tool.ts`。

**番頭の方針（決定済み・この仕事で覆さないこと）：稼働の実態＝`always` を正とし、リポジトリを
合わせる。** `exit(0)` での自己再起動は道具の設計上の前提であって事故ではない。

## やること

### 1. `deploy/banto.service` を直す
`Restart=on-failure` → `Restart=always`。**同じファイルのその直前に、なぜ `always` なのかを
コメントで書く**——「`system.restart` は `exit(0)` で終わる（正常終了での自己再起動が設計上の
前提）ので、`on-failure` だと撃った瞬間に上がってこない」。コミットの説明にも同じ理由を書く。

### 2. 他のユニットも稼働機と突き合わせる（1つ見つかったなら他にもある）
対象は **4つ**：`banto.service` / `banto-worker-pool.service` / `banto-environment-pool.service` /
`banto-daemon.service`。

- 稼働機側は `systemctl cat <unit>` か `/etc/systemd/system/<unit>` を読むだけでよい
  （**`sudo` は通らない。読むだけなので要らない**）
- **稼働機のユニットファイルは絶対に書き換えないこと。** この仕事で触るのはリポジトリ側だけ
- 全行を突き合わせ、食い違いを拾う（`Restart=` に限らない。`Environment=` / `ExecStart=` /
  `KillMode=` / `ReadWritePaths=` なども見る）
- **稼働の実態が正しいと言い切れるものだけ**リポジトリを合わせる。判断がつかないもの・
  どちらが正か言えないものは**直さず**、inc-0072 に「未決」として理由つきで残すこと
  （勝手に決めない。I2：分からないものを分かったことにしない）

### 3. 記録に残す（`work/inbox/incident/inc-0072-deployed-unit-differs-from-repo.md`）
- 4ユニットぶんの突き合わせ結果を**表**にする（ユニット名／食い違った鍵／稼働機の値／
  リポジトリの値／どちらを正としたか／理由）。食い違いが無かったユニットも「食い違い無し」と
  明記する（見ていないのか無かったのかが読めるように）
- `Restart=always` を正とした理由（上の背景）を本文に書く
- front matter の `status:` を `resolved` にする

### 4. 試験を置く（`tests/acceptance/deploy-unit-restart-policy.spec.ts`・新規）
node:test で、**リポジトリのファイルを読むだけ**の試験にする（コンテナから systemd には
届かないので、稼働機は見られない。見ているのは「変更の意図」であって稼働の姿ではない、と
ファイル冒頭のコメントに明記すること——`tests/acceptance/restart-blast-radius.spec.ts` の
「この試験の限界」の書き方に倣う）。

落とすもの：
- `deploy/banto.service` の `Restart=` が `always` でない
- そのファイルに `exit(0)` の理由コメントが無い（`exit(0)` の語で見てよい）
- 他3ユニットの `Restart=` が、この仕事で突き合わせて確定した値と違う（値は試験の中に
  定数表として持ち、いつ何と突き合わせたかを添える）
- inc-0072 の記録に4ユニットの名前が揃っていない、または `status:` が `resolved` でない
