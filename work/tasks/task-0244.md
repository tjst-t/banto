## 何が起きているか（**急ぎ**）

**いま main の `npm run typecheck` が落ちています。**番頭が袋の外で実測しました
（`env.verify` / profile test / `env-b083e5b943` / **終了コード 2**）：

```
tests/acceptance/trunk-folds-branch.spec.ts(196,26): error TS2339:
  Property 'text' does not exist on type 'TranscriptEntry'.
  Property 'text' does not exist on type '{ role: "branch"; branchId: string; }'.
tests/acceptance/trunk-folds-branch.spec.ts(214,26): 同上
tests/acceptance/trunk-folds-branch.spec.ts(215,26): 同上
```

**受け入れ条件に `npm run typecheck` を持つタスクは、中身が正しくてもマージ前ゲートで全部落ちます。**
今夜の列がこれで詰まります（実際に task-0240 がこれで止まりました）。**型エラーだけで、動きは壊れて
いません**——`npm test` は 2692 件すべて通っています。

## 原因

`branch.transcript.find((e) => e.role === "notice" && /…/u.test(e.text))` で、
`TranscriptEntry` の判別が効かず、`text` を持たない要素（`{ role: "branch"; branchId: string }`）が
候補に残っています。196 / 214 / 215 行目の3か所です。

## やること

**`tests/acceptance/trunk-folds-branch.spec.ts` だけを触ってください**（製品コードは触らない）。

- 述語を型で絞る形にする。例（形は任せます）:
  ```ts
  const notice = branch.transcript.find(
    (e): e is Extract<TranscriptEntry, { text: string }> =>
      e.role === "notice" && "text" in e && /幹が畳みました/u.test(e.text)
  );
  ```
- **試験が何を主張しているかは1文字も変えないこと。**「幹が畳みました」が枝の記録に残ること、
  結論の文言が読めること、枝自身の結論が併記されること——**assert の中身と件数はそのまま**。
- `as any` で黙らせないこと（I2）。型の側で正しく絞ること。
- **製品の型（`TranscriptEntry` の定義）は触らない。** 直すべきは検査の書き方で、いま製品の型を
  動かすと今夜の列に別の波が立ちます。必要だと判断したら**直さずに報告だけ**してください。
