## 目的

ADR-0010 決定20 で決めた「モジュール → Banto の汎用の受け口」を実装する。Kobo の既存の状態遷移ロジック（健康状態taxonomy・TTL超過検出・blocking発生）が閾値を超えた際、Kobo が自動でセッション開始リクエストをイベントとして発行し、Banto が既存の WebSocket 購読でリアルタイムに受け取る。

## ユースケース

- Kobo 側でタスクが stalled/zombie 等の閾値を超えると、Kobo がセッション開始リクエストイベントを自動発行する
- Banto はこのイベントを WebSocket 購読で受け取り、リクエスト一覧に表示する。PO が選ぶと、文脈タグ（と指定があればカタログの GUI）が注入された新セッションが始まる
- リクエストの既読・重複排除は Kobo 側のイベントログ（"consumed" イベント）に一本化されており、Banto は別ストアを持たない
- カタログに存在しない GUI kind が指定されたリクエストは、GUI指定を無視して文脈タグのみのバナー表示にフォールバックする

## スコープ外

- Kobo の状態遷移ロジック（健康状態taxonomy等）自体の変更（既存実装。今回は「閾値超過→イベント発行」の配線のみ）
- 複数モジュールの優先順位付け（モジュールが増えてから設計する。ADR-0010決定20で明記済み）
- PO/番頭による手動昇格（今回は作らない。ADR-0010決定20で明記済み）
