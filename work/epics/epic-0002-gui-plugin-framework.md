## 目的

ADR-0010 決定12・16〜18・21 で決めたキャンバス機構を実装する。チャット＋キャンバスの2ペインUI、React コンポーネント直接 import 方式での GUI 描画、GUI カタログ（Tool契約＋component参照）、5種の基本GUIセット（ファイル/ディレクトリ・DIFF・ブラウザビュー・シェル・セッションビューア）を提供する。

## ユースケース

- 番頭がカタログから GUI を Tool 呼び出しで開くと、対応する React コンポーネントがキャンバスのタブとして直接レンダリングされる（iframeなし）
- PO がカードの「相談する」を押す、または番頭が `canvas.query_state` 相当の Tool でキャンバス状態を参照する、のいずれの経路でも文脈がチャットに渡る
- Kobo の Extension Pack が登録したプラガブル GUI（アテンションキュー・エージェントボード・バックログ編集）がカタログに現れ、開ける
- モバイル幅で GUI コンポーネントが崩れず表示される（banto-core が提供する共通レスポンシブ基盤に各コンポーネントが従う）

## スコープ外

- Kobo 側の実際の Extension Pack 実装（アテンションキュー等のコンポーネント本体。Kobo側の別епicとして今後起票）
- 番頭核ホストのターンループ・Tool契約の土台（epic-0001）
- セッション開始リクエストの GUI 指定バリデーション（epic-0004）
