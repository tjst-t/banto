# フェイルオープンが、自分で入れた指標を欠測させる

## 何に気づいたか

ADR-0027（監査は補助の目）で2つのものを同時に入れた。

- **決定142**：監査人が判定を出さなければ**既定で通す**（フェイルオープン）
- **決定143 / 受け入れ条件 a11**：監査人が **diff の外を読んだら、その理由を `audit_report` の `consultedBeyondDiff` に書かせ、`audit_verdict` に残す**

狙いは「**diff だけでは足りない頻度が数字で分かる**」こと——「監査は diff で足りる」は**いまは仮説**なので、確かめられる形にしておく、というのが PO の指示だった。

**この2つは噛み合っていない。**

`consultedBeyondDiff` は **`audit_report` の欄**である。つまり**監査人が判定を出したときにしか埋まらない**。
ところが決定142 により、**判定を出さない回は既定で通って先へ進む**。

**結果、既定通過した回は「遡ったかどうか」も「なぜ遡ったか」も丸ごと欠測する。**

## 実測（2026-08-20 / task-0292）

task-0292 の監査は `byDefault: true` で既定通過した（`defaultReason` は `audit_reported_without_verdict:`）。

そのときの監査セッションの記録を読むと、**監査人は実際に diff の外を読んでいた**。

```
sed -n '590,620p' docs/notes/handoff.md
grep -n "監査|reasoning|上限|等級" docs/spec/daemon-core.md
sed -n '230,300p' docs/spec/daemon-core.md
```

**diff に無いファイルを3回読んでいる。** しかし判定を出さずに終えたので、`audit_verdict` に `consultedBeyondDiff` は残っていない。

**この1件は、指標の母数からも分子からも消えている。**

## なぜ害か

**「diff だけでは足りなかった頻度」が、実態より低く出る。**

しかも**偏り方が悪い**。欠測するのは「**監査人が判定を出せなかった回**」であり、それは**手間取った回・迷った回**である可能性が高い。つまり**いちばん「diff だけでは足りなかった」側に寄っているはずの回が、優先的に欠測する。**

この数字は「**監査は diff で足りる**」という仮説を確かめ、**次にどこまで絞れるかを決めるための材料**である。**低く出れば「もっと絞れる」と読んでしまう。** 指標が、確かめたかったことの逆へ誘導する。

## 直す方向（案）

**遡った事実は、機構の側で数える。**

監査人がどのファイルを読んだかは、**自己申告ではなく実行記録から取れるはず**である——監査セッションの記録には、監査人が叩いた `Read` / `Bash`（`sed` / `grep`）が全部残っている。**渡した diff に含まれるファイルの集合**と突き合わせれば、「diff の外を読んだか」は**機械的に判定できる**。

そうすれば：

- **判定を出したかどうかに依存しない**（既定通過の回も数えられる）
- **自己申告ではなく事実になる**（I1 と揃う）
- **監査人が書き忘れても数字が欠けない**——**フェイルオープンの精神と同じ**（忘れても機構が拾う）

`consultedBeyondDiff`（自己申告の**理由**）は、それはそれで残してよい。**「何を読んだか」は機構が数え、「なぜ読んだか」は監査人が書く**、という分け方が自然である。**いまは両方を監査人に頼っていて、片方が落ちると両方落ちる。**

## なぜ task ではなく imp か

**急ぎではない**（指標の精度の話で、工程は止まらない）。かつ、いま工場には ADR-0027 の後始末が何本も走っている。**席を食わせない。**

**ただし放置ではない。** ADR-0027 に「この指標にはこういう欠測がある」と注記してあるので、**数字を読む人は騙されない**。直すのはそのあとでよい。

## 教訓

**指標を入れたら、その指標がどこで嘘をつくかを先に書く。**
今回は「安全側に倒す変更（フェイルオープン）」と「見張るための指標」を同じ設計に入れたのに、**前者が後者を壊す**ことに、入れた時点では気づいていなかった。**同じ日に、同じ形の見落としを2回している**（もう1つは task-0294：フェイルオープンの引き金が「監査人が起きたあと」にしか無く、起きなかった場合を誰も拾わない）。

**安全側に倒す変更は、別の見えなさを作る。** 倒したあとに「**これで見えなくなるものは何か**」を必ず数えること。
