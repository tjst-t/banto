# タスクを「誰が持っているか」が道具の上に無い

## 何が起きたか

2026-08-20、`task-0289`（残高切れで会話が黙る穴を塞ぐ）が `merging → failed` で落ちた。原因は task-0289 の中身ではなく、**main のチェックアウトに残っていた未コミット差分**が `server.ts` を上書きしてしまい、`git merge --ff-only` が中断したことだった。

幹（`thread-61`）は、この件を持っている枝 `thread-239`「task-0289 が監査で立ち往生」へ段取りを渡そうとして、断られた。

```
thread.steer({ threadId: "thread-239", ... })
→ task-0289 が監査で立ち往生 はこの幹の枝ではありません。
　 他の幹の枝には渡せません（用があるならその幹へ thread.send）
```

`thread-239` は**別の幹**から生えている（task-0289 の知らせの宛先が `thread-231`「402 がまだ出る」で、そこから開き直った枝だった）。幹からは **steer もできず、`thread.read` で中を見ることもできない**。

そこで幹は自分の枝 `thread-244` を開き、未コミット差分の処置と task-0289 の通し直しを持たせた。ところが——

- **08:46:45 / 08:46:50** — 番頭名義（`steward@banto.local`）のコミット2本が main に積まれた（`b6e4fec6` / `0616e6d1`）
- **08:47:16** — 同じく番頭名義で `task-0289` の `reverify` が打たれた

**どちらも `thread-244` の仕業ではない。** thread-244 の職人が `git add` した時点で index には何も乗らず（HEAD が既にその内容だった）、コミットは1本も作っていない。着手前に控えた12ファイルの blob ハッシュは現在値と全件一致していて、作業ツリーは1バイトも動いていない。**同じ件に、二人が同時に手を出していた。**

## なぜ実害が出なかったか

**たまたま、両者の結論が同じだったから。** 先に動いた側も「main へそのままコミットする」を選び、内容も同じだった。

もし片方が「wip ブランチへ退避する」を選んでいたら、もう片方が同じファイルをコミットしようとして、main の履歴か稼働中のチェックアウトが壊れていた。**稼働中の banto はこのチェックアウトの `.ts` を直読している**ので、作業ツリーの取り違えは本番の退行に直結する。

## 構造的な原因

1. **工場の道具（`kobo.*`）は、どの会話からでも叩ける。** `kobo.reopen` も `kobo.settle` も、その仕事を持っている会話かどうかを見ない。
2. **一方、会話の道具（`thread.steer` / `thread.read`）は幹の境界で止まる。** 別の幹の枝には手が届かない——これは設計どおりで、正しい。
3. その結果、**「持ち主には手が届かないのに、仕事そのものには手が届く」**という非対称が生まれる。番頭は良かれと思って自分の枝を立て、二重の手になる。
4. `kobo.task` は「知らせの宛先: thread-231『402がまだ出る』（畳んである・知らせが来たら開き直る）」と**表示はしていた**。だが読んでも「それが自分の幹の枝なのか、別の幹の枝なのか」は分からない。**判定に必要な情報が出ていない。**

## 直しの候補

- **(a) 持ち主を明示する。** `kobo.task` / `kobo.list` の表示に、宛先が**この会話から手が届くか**を出す（「あなたの枝」／「別の幹の枝（手は届かない）」）。読むだけで二重を避けられる。
- **(b) 手を出すときに警告する。** `kobo.reopen` / `kobo.send_back` / `kobo.settle` / `kobo.abandon` が、呼び出し元と異なる会話が持つタスクに対して**断りはしないが一言添える**（「このタスクは thread-239 が持っています。二重に手を入れていないか確かめてください」）。断ると袋小路（持ち主が黙っている場合に誰も動かせない）になるので、**止めるのではなく見えるようにする**。
- **(c) 知らせの宛先が畳んだ枝のとき、開き直す先を選べるようにする。** 今回の宛先 `thread-231` は「畳んである・知らせが来たら開き直る」枝だった。畳んだ枝が起き上がって仕事を持つと、他の会話からは所在が読めない。

## 教訓

- **「手が届く」と「持っている」は別物である。** 工場の道具が叩けることは、その仕事を自分が持っている根拠にならない。
- 番頭が別の枝を立てる前に、**`kobo.task` の「知らせの宛先」を読み、それが自分の幹の枝かを確かめる**こと。届かない相手が持っているなら、`thread.send` でその幹へ渡すのが筋で、自分で持ち直すのは最後の手段。
