## 内容

**番頭が喋り出すと、10回に1回、本文が途中で止まったまま動かなくなっていた。**

`tests/chat-ux.spec.ts`「上へ動かした瞬間に追従が止まり、↓ボタンが出る」が間欠的に
落ちていたのが入口。落ちていたのは**本題の前**——`fillConversation` を終えた時点で
既に ↓ボタンが出ていた（＝最下部にいない）。つまり試験の書き方の問題ではなく、
**追従そのものが働いていなかった**。

## 実測

40回まわして、届き終わってから3秒ぶん `scrollHeight - scrollTop - clientHeight` を
250ms ごとに採った：

```
RUN  6 gaps=636,636,636,636,636,636,636,636,636,636,636,636
RUN  9 gaps=626,626,...
RUN 10 gaps=738,738,...
RUN 30 gaps=248,248,...
```

**4/40。しかも一度も回復しない。** POには「番頭の返事が途中で止まった」ように見える。

scroll と resize の時系列も採った：

```
2   resize top=0   h=664  ch=664
43  resize top=0   h=1510 ch=664     ← 中身が一気に伸びる
106 scroll top=137 h=1510 ch=664
122 scroll top=181 h=1510 ch=664     ← ここで止まる（本来は 846 まで行く）
```

`scrollTop` は**一度も下がっていない**。上へ動かされたわけではなく、
**追従の spring が途中で死んでいる**。

## 原因（上流のバグ）

`use-stick-to-bottom` 1.1.6 の `handleScroll`：

```js
if (ignoreScrollToTop && ignoreScrollToTop > scrollTop) {
  lastScrollTop = ignoreScrollToTop;      // 自分が代入した値
}
...
const isScrollingUp = scrollTop < lastScrollTop;
if (isScrollingUp) { setEscapedFromLock(true); setIsAtBottom(false); }
```

追従の1フレームは「伸びた先へ `scrollTop` を代入する」。**中身の組み直しが間に合って
いないと器がその値を受け取れず、ブラウザが切り詰める。** ライブラリは切り詰められた
値を次の scroll で読み、「自分が代入した値より小さい＝POが上へ動かした」と判定して
追従を切る（`escapedFromLock`）。切れると二度と戻らない
（`if (!state.isAtBottom) { state.animation = undefined; return false; }`）。

**inc-0041 と同じ穴の別の面。** あちらは面から戻ったときの貼り付き直し、こちらは
喋っている最中の追従で、どちらも「ライブラリに任せた判断が、実際には競争になっていた」。

### 却下した直し方

- **`resize` を spring から瞬間移動へ。** 直ったように見えて、**起きる場所が次の応答へ
  移るだけ**だった（「最下部にいる間は、届いた分だけ追いかける」が 33% で落ちるようになる）。
  代入が1フレームで終わっても、切り詰めは起きる
- **ライブラリの更新。** 1.1.6 が最新で、上流に直しは無い

## 直したこと

**追従が切れてよいのは、POが自分で上へ動かしたときだけ**、という決めを画面側で持つ。

- 器で起きた仕草（ホイール・触れる・押す・キー）の時刻を控える
- 追従が切れたとき、直前 400ms に仕草が無ければ**貼り直す**

ライブラリの内部状態は覗かないし、追従の条件を書き直してもいない（D5）。持ったのは
「切れた理由がPOの操作なら従う、そうでなければ貼り直す」という判断だけ。

猶予を 400ms と広めに取ったのは、**逆向きの間違いのほうが害が大きい**から——POが
自分で読み返しているのに機械が下へ引き戻すのは、止まって見えるより不快。惰性で流れる
操作は転がすたびに時刻が更新されるので、長くても困らない。

## 確かめたこと

同じ計測（30回 × 3応答＝90バースト）を、直す前と後で：

| | 止まったまま動かない |
|---|---|
| 直す前 | **9 / 90** |
| 直した後 | **0 / 90** |

`tests/chat-ux.spec.ts` の末尾追従4件を 8回ずつ（32件）——**上へ動かしたら止まる**・
**70px の内側でも止まる**を含めて全部通る（貼り直しがPOの操作を潰していない）。
