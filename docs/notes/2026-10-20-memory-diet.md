借りる考え（案。決まったことではない）：
- **台帳と置き場を分ける**：毎ターン全部入れるのは「必ず守る決まり」の小さな台帳（上の残す行）だけ。経緯・実測は要るときに引く。
- **元の証拠と、要約・判断を分けて持つ**：証拠はコミット・試験の数字・ノート（git と docs/notes にもうある）、要約・判断は仕様（docs/specs）。
  新しい置き場をすぐ作らず、まずはこの3つ（git・docs/notes・docs/specs と Backlog）を置き場とみなす。
- **引くのは LLM を使わない検索、引くかは AI が tool で決める**：毎ターン自動で差し込まない（取りこぼしと無駄が出る）。
  今は Shell の grep と FileSystem の読み取りで足りる。足りなくなったら、banto の Memory の Module に「経緯を探す」tool
  （全文検索、置き場は docs/notes と取り消した Memory の行）を足すのを考える。
- **時刻と「何に置き換わったか」を持つ**：revise_memory はもう取り消しの理由と置き換え先を記録に残している。取り消した行を
  経緯として引けるようにすれば、消した Memory の行も探せる。
