# チャットの題を付ける（Backlog #498）——仕様に無かった細部の決め方

2026-10-21。仕様は v4-architecture.md §2.2「題は AI が付ける」（ローカルでは写し `2026-10-21-chat-spec.md`）。実装は
`banto/packages/core/src/http/chat-title.ts`、呼ぶのはターンを開く口（`app.ts` の `openTurn`）で、ターンが終わって人の書き込みが記録に残っているときだけ。

- **「人が名前を変えていなければ」は、名前がまだ仮の「新しいチャット」かで見る**。記録に「人が変えたか」の印は足していない
  （read model の形を変えると SnapshotProjection の版を上げることになる）。人がわざわざ「新しいチャット」に変え直した場合は
  変えていないのと同じに扱う。小さいモデルを待っている間に人が変えることがあるので、積む直前にもう一度見る
- **「最初のターン」も同じく名前で見分ける**。題を付けた時点で仮の名前でなくなるので、2回目以降は付けない。最初のターンの題付けが
  host の再起動で途切れたら、次のターンで付く（仮の名前のまま残るよりよい）。待っている間に次のターンが始まっても重ねて呼ばないよう、
  作っている Project を覚える
- **題を付け始めるのはターンが終わってから**（訂正・2026-10-21、レビュー）。最初はターンを開いた直後（Module を起こす前）に
  付け始めていたが、それだと下ごしらえの途中で止めたターンや、AI が何も出す前に止めて書き込みを取り消したターン（§6.31、
  書き込みは入力欄に戻り会話に残らない）でも、取り消した文から名前が付いて残る。名前が仮のものでなくなるので、次に本当の最初の
  書き込みを送っても題は付かない。書き込みを積んだあとでも取り消しはありうる（止めたターンの片づけ `settleStoppedTurn` が決める）
  ので、確かなのはターンが終わってから。そのターン（`lastTurn` が替わった）で積んだ人の発言が記録に残っているかを見る。
  仕様の「最初のターンを始めたら」より少し遅れる（画面の「題を考えています…」が出るのは返事のあと）
- 渡すのは送られた書き込みそのもの。Thread の記録から読み直さない
- 題は 30 文字まで（超えたら「…」で縮める）。小さいモデルの答えは前置き（`Title:`）・囲みの引用符・末尾の句点を落とし、何も残らなければ
  最初の文の題にする
- **試験（E2E）では小さいモデルも偽物**（訂正・2026-10-21、レビュー）。`BANTO_FAKE_RUNNER` の偽の Runner（`e2e/fake-runner.ts`）が
  `oneShot` を書き出し、既定は決まった題「試験の題」。書き込みに `[[fake-title:…]]` で題を指定、`[[fake-title-fail]]` で失敗させる
  （最初の文の題の経路）。**偽の Runner に `oneShot` が無ければ core は立ち上がりを止める**——最初は「無ければ本物の CLI」にして
  いたが、E2E は実 LLM を使わない・実物へ黙って落ちない（`e2e/start-core.ts`、2026-09-20）の決定に反し、機械にログインがあるか
  で題が変わる（規則6 の種）
