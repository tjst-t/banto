# 自動化の時計の実装で決めた細部（2026-10-15、Backlog #316 `automation-clock`）

アーキ仕様 §4.3「時計」を実装したときに、仕様に書かれていない細部を決めた。仕様 §4.3 はこのブランチには無く `main` にある
（abafa075）——仕様書への反映は取り込むときに人が判断する（規則8）。

## 決めたこと

- **置き場**：計算は `automation/schedule.ts`（時計を持たない純粋な関数）、刻みは `automation/clock.ts`（`AutomationClock`）。
  届ける判断（前の回が終わっていない・閉じている等）は今までどおり `runner.ts`——時計は「いつ・何回目を」だけ決める
- **cron の式の部品は `croner`（10.0.1、固定）**。理由：Node 標準に式を読む部品が無い。croner は依存が0でタイムゾーンを
  `Intl` で扱う（cron-parser は luxon を連れてくる）。受けるのは5つの欄（分 時 日 月 曜日）だけ——秒の欄・`@daily` 等は断る。
  日と曜日を両方書いたときは croner の既定（どちらかに合えば、従来の cron と同じ）
- **最短15分の確かめ**：cron の式は先の回を1年ぶん（最大 2000 回）並べて、間が15分より短いところがあれば断る。
  N 時間ごとは時間の単位なので下回れない
- **次の時刻は保存しない**（規則3）。fold に `clockFrom`（時計の数え始め）を持ち、毎刻み計算し直す。`clockFrom` は
  作った・きっかけ（`source`）を変えた・再開した時刻と、時計の回（`automation.fired` の `scheduledFor`）の予定の時刻の一番後。
  名前・指示を変えただけでは動かない。snapshot の版を 2 に上げた
- **`AutomationRun` に `scheduledFor`（予定の時刻）と `delayed`（ずらした理由）を足した**。`at` は実際に動いた時刻
- **夏時間**：重なり（同じ壁時計が2回）は早いほう1回だけ、飛び（その壁時計が無い）は飛んだ直後（例：New York の 2:30 は
  その日だけ 3:00）。N 時間ごとの格子は、その土地の 1970-01-01 0:00 から N 時間刻み（N が 24 の約数なら毎日 0:00 から）。
  1時間ごとは夏時間の終わりの日に、重なる1時間ぶんを1回だけ動かす（次は 2:00 標準時）
- **刻み**：毎分 0 秒の 0.5 秒あとに揃える（`setTimeout` を毎回1分以内で積み直す。長いタイマーは積まない）。刻みは重ならない。
  E2E だけ `BANTO_AUTOMATION_CLOCK_INTERVAL_MS` で縮める
- **取り戻し**：数え始め〜今に入る時刻が2つ以上あれば、一番最近の1回を動かし、ほかは**1件の `skipped` にまとめて**残す
  （予定の時刻は最初の回、理由に回数と最初の時刻）。15分ごとを1週間止めれば 670 回あり、1回ずつ書くと台帳の直近 50 件が
  それで埋まるため。起動して最初の刻みの理由は「banto が止まっていた間」、走っている途中なら「時計が進んでいなかった間
  （機械が眠っていた等）」。数えるのは 10,000 回まで（超えたら「以上」と書く）
- **同時本数**：上限 `AUTOMATION_MAX_CONCURRENT = 3`（仮置き）。数えるのは結末が出ていない（`running`）回のうち、ターンが
  走っているか届けものが積まれる前のもの——落ちて結末を書けずに残った `running` で枠が埋まり続けないように。超えた分は
  2分ずらし（手元に覚える。台帳には書かない）、動いた回に `delayed` で理由を残す。ずらしている間に次の時刻が来たら、
  古い回は `skipped`（理由つき）にして新しい回を動かす。ずらしている間に banto が止まったら、起きたときの取り戻しで動く
- **一時停止中**は数えない（再開した時刻から数え直す——止めていた間の分を再開した瞬間に動かさない）。**Project が閉じている間**
  は動かさず、記録もしない（15分ごとに `skipped` が積もらないように）。開き直したら次の時刻から
- **起動の順**：`app.listen` の中で `deliveries.resumeAll()` のあとに `automationClock.start()`。止める信号で刻みを止める

## 残したこと

- Project を閉じている間に banto を起こし直し、開き直したあとに起こし直すと、閉じていた間の時刻を「止まっていた間」として
  1回取り戻す（閉じていた間に動かさなかったことを台帳に残していないため）。困ったら、開き直した時刻を数え始めに入れる
- 上限の 3 本・ずらす 2 分は仮置き。資源の順番待ち（Backlog #277）ができたらそこに並べる
- 画面に次の時刻を出すのは `automation-canvas`（`nextFireAt` を GET に足すならそこで）
