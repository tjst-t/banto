# Backlog Module の本実装（2026-10-03）

仕様は `docs/specs/v4-modules.md` §4.4（「実装」の節）。ここは決め方と、却下した案と、踏んだもの。

## 決めたこと・その理由

- **人の画面の口を admin の tool として別に持った**（`getBoard`・`board*`）。画面は agent の tool も呼べる
  （`checkUiCallable` は `module` 可視性だけを断る）が、(1) AI 向けの返り値は文脈を食わないよう短くしてあり、
  画面が要る「一覧の全部」は入っていない、(2) 書いた後に一覧を読み直す往復を1回にしたい、の2つで分けた。
  処理は同じ関数（`model.ts` の操作と店の列）を通るので、決まりごとは1箇所（規則3）。
  却下：agent の tool だけにして画面が毎回 `getBoard` を呼び直す——往復が倍になり、間に AI の変更が挟まると
  「押したのに違うものが出る」が起きうる
- **画面の読み直しは3秒ごと・見えている間だけ・版が同じなら中身なし**。Module の画面で読み直しをしている前例が
  無かった（repositories 等は人の操作の後にだけ読む）。host から「変わった」を知らせる口は無い——作るなら
  core を広げることになるので今回はやらない（仕様の「まだ決めていない」へ）
- **「手で入った前からある問題」は関係のない変更を止めない**。最初は「書いた後の文書が全部正しいときだけ書く」に
  していたが、今の docs/tasks.json を変換すると id の重複が1件あり（下）、これだと**どの操作もできなくなる**。
  「変える前に無かった問題が増えるときだけ断る」にした。前からある問題は読むたびに知らせる（黙らない）
- **id に `.` と `_` を許した**。今の docs/tasks.json に `agent-sdk-0.3.281` がある。slug を `-` だけに絞ると
  変換で id を書き換えることになり、git の履歴やノートからの参照が切れる
- **`createdAt`・`updatedAt` に `null` を許した**。古い形には日時が無い（done 127件のうち completedAt があるのは
  86件だけ）。変換した日を入れると嘘になる（規則3——分からないものを作らない）
- **いちばん外側に `extra`**。古い形の `phase0`・`phase1`（閉じた日・閉じた根拠）と `$comment` は項目ではないので、
  落とさずに運ぶ場所が要った。`milestones` に欄を足す案もあったが、仕様の形（id・title・status）を広げることになる
- **詳細の「待つものを足す」は、これを待っている相手を最初から候補に出さない**（モックと同じ）。2項の輪はそもそも
  作れない。遠回りの輪は Module が経路つきで断る（E2E で `store → screen → agent-tools → store`）
- **「取り組んだ Thread」はリンクにしない**。モックは会話へのリンクだったが、Canvas から banto の会話を開かせる口が
  無い（`ui/open-link` は http/https だけ）。押せるように見せて押しても何も起きない、は規則13 に反する
- **Thread の刻印（`dev.banto/thread`）は AI の代理の1経路だけ**。台帳（`ModuleCallTracker`）を引く案もあったが、
  代理（`agent-proxy`）がそのターンの Project と Thread を直接持っているので、そこで刻めば足りる（core の変更は
  `agent-proxy.ts` の刻む1箇所と `meta.ts` の定数・読む関数だけ）。第三者の Module に Thread の id を渡すことの是非は
  未決（アーキ仕様 §10 の 32）

## 見つけたもの

- **今の docs/tasks.json に id `module-registry-install` が2件ある**。変換スクリプトは直さずに運び、
  「直すところ」として出す。どちらを残すかは人が決める（規則8）
- `"phase": "Phase 0"` と `"phase": "0"` が混ざっている（1件だけ前者）。変換では同じマイルストーンにした
- 会話の隣の Canvas は 1280px の画面で約 690px。モックと同じ決まり（48rem 未満なら詳細が一覧と入れ替わる）なので、
  ふつうの幅では詳細を開くと一覧が隠れる。大きく開く（⤢）と並ぶ

## 確かめ方の記録

- E2E はこの機械（Project のコンテナの中）では `sg incus -c "…"` で回す（入れ子の Incus のソケットが incus
  グループ）。global-setup が claude の資格情報ファイルの有無を見るが、E2E は偽 Runner なので使わない——
  中身の無いファイルを一時の場所に置き `CLAUDE_SECURESTORAGE_CONFIG_DIR` で指した（人の資格情報は借りていない）
- 画面は先に、MCP Apps の受け手だけを真似る小さな host（`/tmp` に置いた使い捨て）で撮りながら直し、
  最後に E2E の隔離した host で撮った
