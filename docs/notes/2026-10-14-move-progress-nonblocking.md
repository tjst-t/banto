# 移すを押したら小窓を閉じ、画面を止めずに進み具合を見せる（Backlog #293）

2026-10-14、ユーザー要望（qemu-bmc を戻したとき）：「移す」を押すと「写しています…」の小窓が出たまま閉じられず、画面全体が
操作できなくなった（Dialog は下の画面を inert にする）。移すのは数分〜1時間かかるので、そのあいだ他の Project の会話も触れない。

## 決めたこと

- 押して受け付けられたら（POST が 202）小窓を閉じる。写している段は小窓に持たない
- 進み具合は #270 の帯・サイドバーの印に加え、Project の設定「一般」の実行場所の欄に出す（どこへ・段・写した量 / 全体）。
  帯にも段を足した。移している間は設定の「移す」を押せない
- 終わったら、帯と設定の欄に「△△ へ移しました。root は ○○ です。元は □□ の ○○ に残っています」を出す（人が閉じるまで）。
  失敗の帯は #270 のまま、設定の欄にも同じ文
- host の `runtime_move.changed` に `done`（どこからどこへ）を足した。画面が移している間の写し（`moving`）から終わりの文を
  作ることもできたが、その間に流れが切れていると作れない——終わったと言う host から受け取る

## 決めなかったこと・残したもの

- **閉じた Project の再開を断られて履歴から開いたとき（`onMoved` を渡す）は、今までどおり小窓の中で終わりまで見せる**。
  閉じた Project には会話の面の帯もサイドバーの行も無く、設定の欄も開けない——閉じると進み具合を見る場所が無くなる。
  終わったら「再開する」を押させたい。ここも止めずに見せるなら、履歴の小窓の行に出す形を別に決める
- 「移しました」の帯・欄は画面のメモリだけ（読み込み直すと消える）。正本は各 Thread への「移した」の知らせ
