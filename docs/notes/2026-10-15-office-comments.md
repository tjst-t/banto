# PDF のコメントと「AI に返す」（Backlog #307 office-comments）を実装して決めたこと（2026-10-15）

仕様は `docs/specs/v4-modules.md` §2.2「PDF・Office のファイルを読んでコメントを返す」の「コメント」と
`docs/specs/v4-frontend.md` §6.2「画面から会話の入力欄へ文を渡す——`ui/message`」。ここは経緯と却下した案。

## 入力欄の塊を何で持つか

- **採った案**：assistant-ui の添付（`CreateAttachment`、type `banto-canvas-quote`、中身は文1つ）。送信ボタンが文の無いときも
  押せる（画面から返したものだけを送れる）、送った発言の添付としてそのまま描ける、× で外せる、が全部そのまま付いてくる。
  出所（Module・第三者か・どの画面か）は添付の id に JSON で持たせた——添付には任意の項目を足せない
- 却下：入力欄の外に Thread ごとの置き場を作って composerHint に描く——文が空だと送信ボタンが押せず、送った発言にも出ない
  （自前で描き足すことになる）
- 入力欄の受け皿（`ImageAttachmentAdapter`）の `accept` に塊の contentType を足した。assistant-ui はファイルでない添付にも
  `accept` を当てるため。ファイルとしては断る

## 第三者かどうか

画面（ブラウザ）は入力欄で強く出すために `/api/modules` の `origin` を見るが、**送ったときに host が自分の宣言で決め直す**
（本文の `quotes` は `{module, text}` だけ）。Module の名前の形を host で絞り、前置き（囲みの外）に名前を出せるようにした。

## コメントのハッシュ

付けたときのハッシュは FileSystem が付ける（画面が持ってきた値は使わない）。「元に戻す」で戻したものは新しく付けたものとして
置き場に入る（ハッシュと時刻が付け直される）——戻すまでにファイルが変わっていれば、変わったことは分からなくなる。1回だけの
戻しなので、そのままにした。

## 表のセル

表の画面（xlsx、#306）がまだ無いので、画面からセルを指してコメントを付ける口は無い。置き場の形と返す文の形
（`` `シート1!D4`（値 1,200） ``）だけ先に入れ、E2E は置き場の口から1件足して一覧と返す文を見ている。表の画面ができたら、
`CommentTarget` の口（選んだセル → `{kind:"cell", …}`）を足す。

## 残したこと

- 止めて取り消した発言（§6.31）：host の `withdrawn` には塊を載せていない。その画面が送ったターンなら手元の控えから戻るが、
  別の画面（別タブ）が送ったターンを止めたときは文と画像だけが戻る
- 会話の外（launcher のファイルブラウザ）で PDF を document の画面で開く道がまだ無いので、「コピー」は実ブラウザで
  確かめていない（会話の中の画面には `message` を名乗るので「AI に返す」が出る、は E2E で見ている）
