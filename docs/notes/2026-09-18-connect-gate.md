# 繋がっていないときの面と、本文のリンク（2026-09-18）

仕様は `docs/specs/v4-frontend.md` §6.24・§6.25。ここには**なぜ要ったか**と、
**測ったこと**を残す。

## なぜ要ったか——「Project が全部消えた」

https を足した直後（`docs/notes/2026-09-18-https-for-oauth.md`）、ユーザーから
「Project が何も見えなくなった」。**サーバのデータは無事**で、新しいブラウザで
開けば6件そのまま出た。

原因は**オリジンの違い**だった。合言葉はブラウザに**オリジンごと**に保存される
ので、`http://banto.tjstkm.net` で覚えた値は `https://banto.tjstkm.net` からは
**見えない**。

測ったもの：

| 開き方 | Project | API を呼んだか |
|---|---|---|
| 合言葉つき | **6件** | 呼ぶ |
| 合言葉なし・https | 0件 | **1回も呼ばない** |
| 合言葉なし・http | 0件 | **1回も呼ばない** |

**これは https の副作用ではなく、banto の欠陥**だった。呼んでもいないのに
「まだ Project がありません」と言い切っていた——いつか誰かが同じ目に遭う。

## 決めたこと

**外枠より先に、繋がっているかを見る。** 無ければログインの面。

細かいが効くところ：

- **確かめてから覚える。** 通らない値を保存すると、次に開いたときまた同じ
  空っぽを見る（そして原因は前より分かりにくい）
- **合言葉を URL に残さない。** `?bantoToken=` で来ても、覚えたら素の場所へ
  行き直す。履歴とブックマークに焼き付くのを避ける
- **「調べていない」と「無い」を分ける。** 状態は `undefined | null | 設定`
  の3つ——`undefined` の間は**何も断定しない**

## 試験が教えたこと

**日本語の合言葉を打ったら、`fetch` が
「String contains non ISO-8859-1 code point」で落ちた。** 嘘ではないが、
**何を直せばよいか分からない**（規則2）。人が貼っても同じことが起きるので、
載せる前に断って「合言葉に使えない文字が入っています」と言うようにした。

## 本文のリンク

`target="_blank"` と **`rel="noopener noreferrer"` は対**。`noopener` が無いと、
開いた先から `window.opener` でこちらのタブを触れる。

**試験は AI の気分に依存させない。** 書いてもらうのは「そのまま写す1行」だけで、
**4回続けて通ることを測ってから**入れた（`module-settings-canvas` が
「AI がもう一度 tool を呼ぶか」に依存して3回に1回落ちている、という先例がある
——`docs/notes/2026-09-16-secret-placeholder.md`）。

見るのは属性まで（規則14）——「リンクが出た」では、同じタブで開くかどうかが
分からない。

## 残しているもの

- **ログアウト（合言葉を忘れる）の口が無い。** いまは localStorage を消すしかない
- **合言葉が後から無効になったとき**（host の config を作り直した等）は、
  API が 401 を返すだけで、ログインの面には戻らない
