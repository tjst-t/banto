---
title: Terminal
description: 人が操作するターミナル。
---

Terminal は、ブラウザから使える人のためのターミナルです。プロジェクトのコンテナの中で動作します。

- 画面を閉じても、セッションはサーバー側で維持されます。再び開くと、続きから操作できます
- スマートフォンなど、別の端末から同じセッションを開くこともできます
- AI は Terminal を直接操作しません。AI がコマンドを実行するときは [Shell](/docs/modules/shell/) を使います

AI に作業を任せている途中で、手で確認したいことがあるとき（ログを眺める、対話的なコマンドを使うなど）に便利です。

:::note
Terminal はセッションの維持に tmux を使います。[別のサーバー](/docs/admin/remote/)でプロジェクトを動かしている場合は、そのサーバーに tmux をインストールしておいてください。
:::
