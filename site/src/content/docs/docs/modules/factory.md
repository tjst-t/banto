Factory は、[Backlog](/docs/modules/backlog/) のタスクを受け取り、実装から main へのマージまでを自動で進めるモジュールです。

## 処理の流れ

タスク1件ごとに、次の順で処理します。

1. **worktree の作成**：タスク専用のブランチと作業ディレクトリを用意します
2. **実装**：サブエージェントがタスクの内容に従って実装します
3. **テスト**：設定したテストコマンドを実行します。失敗した場合は実装に差し戻します
4. **レビュー**：別のサブエージェントが、タスクの完了条件と照らして変更を確認します。問題があれば実装に差し戻します
5. **マージ**：最新の main に rebase し、テストをもう一度実行してから main に取り込みます
6. **完了**：Backlog のタスクを完了にし、worktree を片付けます

複数のタスクを同時に流すことができます。main への取り込みはプロジェクトごとに1件ずつ順番に行われます。

## 使い方

1. プロジェクトに Factory を追加し、設定でテストコマンドを指定します（テストコマンドが未設定の場合は実行できません）
2. Backlog で、タスクを「準備できた」状態にします（依存するタスクがすべて完了している必要があります）
3. 会話で AI に「#42 を Factory で実装して」などと依頼します

実行状況は Factory の画面で確認できます。タスクごとに、現在の段階、テストの結果、レビューの指摘、変更内容が表示されます。

## 処理が止まった場合

次のような場合、Factory はそのタスクの処理を止め、依頼した会話に理由を通知します。

- テストの差し戻しやレビューの差し戻しが上限回数に達した
- rebase でコンフリクトが起き、自動で解消できなかった

AI が状況を説明するので、続け方（指示を追加して続ける・指摘を承知で取り込む・指定した段階からやり直す・中止する）を伝えてください。中止したタスクは Backlog で「準備できた」に戻り、worktree とブランチは残ります。

## 設定

| 項目 | 既定値 |
|---|---|
| 同時に処理するタスクの数 | 3 |
| テストの差し戻しの上限 | 3回 |
| レビューの差し戻しの上限 | 2回 |
| rebase のやり直しの上限 | 3回 |

実装とレビューに使うエージェント、プロンプトも設定で変更できます。
