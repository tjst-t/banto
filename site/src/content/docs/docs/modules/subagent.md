---
title: Subagent
description: 別の AI エージェントへの作業の依頼。
---

Subagent は、会話中の AI が、別の AI エージェントに作業を依頼するためのモジュールです。調査やレビューなど、独立した作業を並行して進めたいときに使われます。

## 使える AI エージェント

| エージェント | 認証 |
|---|---|
| Claude Code | banto 本体の Claude のログインをそのまま使います |
| OpenCode | banto 全体の設定の「資格情報」で API キーを登録します |

## 依頼のしかた

AI が `runSubagent` ツールで依頼します。依頼すると、会話にサブエージェントのカードが表示されます。カードを選ぶと、サブエージェントの作業の様子を確認できる画面が開きます。

- 完了を待つ依頼と、待たずにバックグラウンドで実行する依頼があります
- バックグラウンドで実行した場合、完了すると結果が会話に届き、AI が再び動き出します
- サブエージェントは、プロジェクトのコンテナの中で動作します

## 停止する

実行中のサブエージェントは、Subagent の画面から人が停止できます。AI が停止するときは、その作業を依頼した会話からのみ停止できます。

banto を再起動した場合、実行中だったサブエージェントの作業は、再起動後に自動で再開されます。
