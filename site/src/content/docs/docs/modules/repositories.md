Repositories は、banto で扱うリポジトリを一覧で管理するモジュールです。GitHub からのクローンや新しいリポジトリの作成を行い、そのままプロジェクトを始められます。

## GitHub アカウントを登録する

Repositories の設定で、GitHub アカウントを登録します。登録方法は2つあります。

| 方法 | 内容 |
|---|---|
| ブラウザでログイン | 画面に表示されるコードを github.com/login/device で入力して許可します。トークンは自動で更新されます |
| PAT（Personal Access Token） | GitHub で作成したトークンを登録します。必要な権限は登録画面の案内を参照してください |

トークンは [Vault](/docs/modules/vault/) に保存されます。

## リポジトリの一覧

一覧は「Project で使っている」と「Project はまだ無い」に分けて表示されます。各リポジトリについて、サーバー上の場所、使用しているアカウント、GitHub 上の場所が表示されます。

一覧からは次の操作ができます。

| 操作 | 内容 |
|---|---|
| URL から clone | GitHub などの URL を指定してクローンします |
| 新しいリポジトリ | 新しいフォルダを作って `git init` します |
| Import する | サーバー上の既存のリポジトリを、その場所のまま一覧に追加します |
| GitHub に公開 | ローカルだけのリポジトリを、GitHub に作成して push します |
| 一覧から外す | フォルダは残したまま、一覧から外します |
| このマシンから削除 | フォルダごと削除します。push していないコミットや未コミットの変更がある場合は警告します |

クローンや新規作成のときに「Project も作る」を選ぶと、続けてそのフォルダをルートにしたプロジェクトを作成できます。

クローン先の既定の場所は `~/banto/<リポジトリ名>` です。Repositories の設定で変更できます。
