## 全般

### どの AI を使いますか？

会話には Claude（Claude Code）を使います。banto をインストールしたサーバーで Claude Code にログインしておくと、そのアカウントで動作します。[サブエージェント](/docs/modules/subagent/)としては、Claude Code のほかに OpenCode も使えます。

### Windows や Mac でも使えますか？

banto 本体は Ubuntu 24.04 または 26.04 のサーバーで動作します。操作はブラウザから行うので、Windows・Mac・スマートフォンなど、手元の端末は問いません。Windows や Mac の上の仮想マシンに Ubuntu を用意して、そこにインストールすることもできます。

### 複数人で使えますか？

現在は1人で使うことを前提にしています。複数人での共同利用には対応していません。

### データはどこに保存されますか？

会話の履歴・設定・シークレットなどは、すべて banto をインストールしたサーバーに保存されます。外部に送信されるのは、AI との会話の内容（Claude の API）と、ご自身で設定した連携先（GitHub など）への通信だけです。

## 安全性

### AI が誤ってファイルを消したりしませんか？

AI の操作はプロジェクトごとのコンテナの中で行われ、ほかのプロジェクトやサーバー本体のファイルには届きません。ただし、そのプロジェクトのフォルダの中のファイルは変更・削除されうるため、Git で管理しておくことをおすすめします。危険な操作は実行前に承認を求めるように設定できます（[受信箱と承認](/docs/guide/inbox/)）。

### AI にトークンや鍵の値を見られませんか？

[Vault](/docs/modules/vault/) に登録したシークレットは、AI には参照名だけが渡され、値はコマンドのプロセスに直接渡されます。会話の中にトークンを直接書き込んだ場合は、その内容は AI に送られます。

### 外出先から使えますか？

画面はブラウザから HTTPS で利用でき、スマートフォンにも対応しています。インターネットに直接公開するのではなく、Tailscale などの VPN を経由して利用することをおすすめします。

## 運用

### アップデートはどうすればいいですか？

「設定」→「更新」から、画面上でアップデートできます。インストールコマンドを再実行しても最新版になります（[アップデート](/docs/install/update/)）。

### banto を再起動すると、作業中の AI はどうなりますか？

再起動によって中断された AI の処理は、再起動後に自動で再開されます。バックグラウンドで実行中のコマンドは、再起動の影響を受けずに実行を続けます。続けて中断が繰り返された場合は自動での再開を止め、受信箱に通知します。

### サーバーのメモリが足りなくなりました。

「設定」→「資源」で、どのプロジェクトの何がメモリを使っているかを確認できます。プロジェクトごとの上限は「設定」→「コンテナ」で調整できます（[リソースの管理](/docs/admin/resources/)）。
