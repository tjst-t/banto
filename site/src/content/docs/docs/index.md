banto は、AI と一緒に進める仕事をいくつも同時に持っても、**いま何がどこまで進んでいて、何があなたの答えを待っているか**を覚えておかなくて済むようにする作業場です。ブラウザから使い、あなたの機械で動きます。

## 解こうとしている問題

AI に仕事を頼むと、待ち時間ができます。待つあいだに別の仕事を頼み、さらに別のプロジェクトにも手を出す——そうして並べて走らせるほど、「あれはどこまで進んだか」「どれが自分の返事を待っているか」を頭の中で追う仕事が増えていきます。

banto の目的は、たくさん並べて走らせること自体ではありません。**並べて走らせても、人が覚えておくことが増えないようにすること**です。

## banto がすること

- **仕事を Project と会話で並べる。** 1つの Project の中で会話を枝分かれ（Fork）させ、同じ文脈から別の試みを並べて進められます。
- **人の番を1か所に集める。** AI が承認や判断を求めているものは受信箱に集まり、サイドバーでも分かります。
- **面倒な道具を最初から持っている。** コマンドの実行、ファイル、秘密の保管、サーバの起動と公開、ブラウザ、バックログ、サブエージェント——これらを Module として、AI と人の両方が使えます。
- **決まった流れは任せられる。** Factory に「worktree を作る→実装→テスト→レビュー→main へ取り込む」を任せ、人は止まったところだけを見ます。

## 動く場所

banto は自分で用意した Ubuntu のマシン（24.04 か 26.04）に入れて動かします。Project ごとにコンテナを作り、AI の作業はその中に閉じ込めます。会話には Claude（Claude Code のログイン）を使います。

入れ方は [入れる](/docs/install/) を見てください。

## いまの状態

banto は1人で使う前提で作っています。多人数での利用はまだ考えていません。
