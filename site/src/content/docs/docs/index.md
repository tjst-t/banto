---
title: banto とは
description: banto の概要と、できること。
---

banto は、複数の AI エージェントに並行して作業を任せても、進捗と確認待ちをひと目で把握できるワークスペースです。ご自身で用意した Ubuntu サーバーにインストールし、ブラウザから利用します。AI との会話には Claude（Claude Code）を使用します。

## 解決したい課題

AI エージェントに作業を依頼すると、完了までに待ち時間が発生します。その間に別の作業を依頼し、別のプロジェクトにも着手する——並行して進める作業が増えるほど、「どの作業がどこまで進んでいるか」「どれが自分の確認を待っているか」を覚えておく負担が大きくなります。

banto の目的は、並行作業の数を増やすことそのものではなく、**作業をいくつ並行させても、人が覚えておくべきことが増えないようにすること**です。

## できること

### 作業の状態をひと目で把握する

プロジェクトと会話はサイドバーに一覧表示され、AI が作業中の会話、あなたの判断を待っている会話、未読の返信がある会話がアイコンや太字で区別されます。AI からの承認依頼や判断の依頼は[受信箱](/docs/guide/inbox/)に集まります。

### 会話を分岐させて、複数の案を並行して試す

会話は [Fork](/docs/guide/threads/) で分岐できます。同じ依頼から複数の実装方針を試したり、本題を止めずに調査を切り出したりできます。プロジェクトで決まった事項は [Memory](/docs/guide/projects/#memory) に記録され、どの Fork にも引き継がれます。

### 組み込みのツールを AI と人で共有する

コマンドの実行、ファイル操作、ブラウザ、シークレットの管理、開発サーバーの起動と公開、バックログ管理などを[モジュール](/docs/modules/)として備えています。モジュールは AI からはツールとして、人からは画面として利用できます。

### 定型の開発フローを自動化する

[Factory](/docs/modules/factory/) に Backlog のタスクを渡すと、worktree の作成・実装・テスト・レビュー・main へのマージまでを自動で進めます。人が対応するのは、処理が止まったときだけです。

### 安全に任せる

AI の操作はプロジェクトごとのコンテナの中で行われます。確認したい操作は実行前に承認を求めるように設定でき、シークレットの値が AI に渡ることはありません。詳しくは[セキュリティ](/docs/admin/security/)を参照してください。

## 動作環境

| 項目 | 要件 |
|---|---|
| サーバー | Ubuntu 24.04 または 26.04（amd64 / arm64）。仮想マシンでも可 |
| ユーザー | sudo 権限のある一般ユーザー |
| ドメイン名 | banto に割り当てるドメイン名（例：`banto.example.com`） |
| AI | Claude のアカウント（Claude Code にログインして使用） |
| 操作する端末 | 最新のブラウザが動作するパソコン・スマートフォン |

banto は現在、1人で使うことを前提にしています。複数人での共同利用には対応していません。
