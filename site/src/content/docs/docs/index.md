title: banto とは
description: banto の概要と、解決しようとしている課題。
---

banto は、AI エージェントとの作業を複数並行して進めても、全体の状況を見失わないためのワークスペースです。ブラウザから利用し、ご自身で用意したサーバー上で動作します。

## 解決したい課題

AI エージェントに作業を依頼すると、完了までに待ち時間が発生します。その間に別の作業を依頼し、さらに別のプロジェクトにも着手する——並行して進める作業が増えるほど、「どの作業がどこまで進んでいるか」「どれが自分の確認を待っているか」を把握しておく負担が大きくなります。

banto の目的は、並行作業の数を増やすことそのものではありません。**作業をいくつ並行させても、人が覚えておくべきことが増えないようにすること**です。

## 主な機能

- **プロジェクトと会話による作業の整理**：プロジェクトの中で会話を分岐（Fork）させ、同じ前提から複数のアプローチを並行して試せます。
- **確認待ちの一元管理**：AI からの承認依頼や判断の依頼は受信箱に集約されます。サイドバーでも、作業中の会話や確認待ちの会話がひと目でわかります。
- **組み込みのツール**：コマンドの実行、ファイル操作、シークレットの管理、サーバーの起動と公開、ブラウザ操作、バックログ管理、サブエージェントなどをモジュールとして備えており、AI と人の両方から利用できます。
- **開発フローの自動化**：Factory を使うと、worktree の作成から実装・テスト・レビュー・main へのマージまでを自動で進められます。人が対応するのは、処理が止まったときだけです。

## 動作環境

banto は Ubuntu 24.04 または 26.04 のサーバーにインストールして使用します。プロジェクトごとにコンテナを作成し、AI による操作はそのコンテナ内に隔離されます。AI との会話には Claude（Claude Code のアカウント）を使用します。

インストール方法は [インストール](/docs/install/) を参照してください。

## 現在の対象

banto は現在、1人での利用を前提としています。複数人での共同利用には対応していません。
