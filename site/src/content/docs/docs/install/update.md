## 画面から更新する

**設定 → 更新** に、今の版と最新の版の差（新しいコミットの件数と題）が出ます。更新には2つの押し方があります。

- **AI が止まるまで待って更新**：動いている会話や仕事が終わるのを待ってから起こし直します。待っている間は、残っているものと、待つのをやめるボタンが出ます。
- **すぐ更新**：途中で切れる会話を確かめてから、すぐ起こし直します。

押す前にパスキーで本人確認をします。新しい版は別のフォルダで組み立ててから切り替えるので、組み立てに失敗しても今の版のまま動きます。新しい版が起きなければ、自動で前の版に戻ります。

起こし直しの途中で切れた AI のターンは、起き直したあと自動で続きます。

## 打ち直す

**入れたときと同じコマンドをもう一度打てば、最新に上がります。** 済んだ段は確かめて飛ばします。

```sh
curl -fsSL https://banto.tjst-t.dev/install.sh | bash
```

- 渡した値だけが変わり、渡さなかった値は前のままです（`/etc/banto/install.conf` に覚えています。秘密は入りません）。
- 例：名前を替える `bash -s -- --domain new.example.com`
- 動いているものが無くなるのを最長30分待ってから起こし直します。越えたら上げずに終わります（空いたら画面の 設定 → 更新 か、同じコマンドをもう一度）。
- 何も変わっていなければ起こし直しません。

## Docker を後から入れたとき

Docker は Incus（コンテナの仕組み）のブリッジの転送を止めてしまうので、Docker を入れたら同じコマンドを打ち直してください。転送を許す設定を置きます。

## Caddy を上げる

install.sh は Caddy が入っていれば触りません。上げるときは：

```sh
sudo /usr/local/bin/caddy upgrade
sudo systemctl restart caddy
```
