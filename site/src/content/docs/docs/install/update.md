## 画面からアップデートする

**「設定」→「更新」** に、現在のバージョンと最新バージョンの差分（新しいコミットの件数とタイトル）が表示されます。アップデートの方法は2つあります。

- **「AI が止まるまで待って更新」**：実行中の会話や処理が終わるのを待ってから再起動します。待機中は、残っている処理の一覧と、アップデートを取り消すボタンが表示されます。
- **「すぐ更新」**：中断される会話を確認したうえで、すぐに再起動します。

実行前に、パスキーによる本人確認が求められます。新しいバージョンは別のディレクトリでビルドしてから切り替えるため、ビルドに失敗しても現在のバージョンのまま動作し続けます。新しいバージョンが正常に起動しなかった場合は、自動的に以前のバージョンに戻ります。

再起動によって中断された AI の処理は、再起動後に自動で再開されます。

## インストールコマンドを再実行する

**インストール時と同じコマンドを再実行すると、最新バージョンにアップデートされます。** 完了済みの手順は確認したうえでスキップされます。

```sh
curl -fsSL https://banto.tjst-t.dev/install.sh | bash
```

- 指定したオプションだけが変更され、指定しなかった値は前回のまま引き継がれます（`/etc/banto/install.conf` に保存されています。シークレットは保存されません）。
- 例：ドメイン名を変更する場合は `bash -s -- --domain new.example.com` と指定します。
- 実行中の処理がなくなるまで最大30分待ってから再起動します。30分を過ぎた場合はアップデートせずに終了します（処理が終わったあとで「設定」→「更新」から実行するか、コマンドを再実行してください）。
- 変更がない場合は再起動しません。

## あとから Docker をインストールした場合

Docker は Incus（banto が使用するコンテナ基盤）のブリッジの転送を停止してしまうため、Docker をインストールしたあとはインストールコマンドを再実行してください。転送を許可する設定が追加されます。

## Caddy をアップデートする

インストーラーは、Caddy がインストール済みの場合は変更しません。Caddy をアップデートするには、次のコマンドを実行します。

```sh
sudo /usr/local/bin/caddy upgrade
sudo systemctl restart caddy
```
