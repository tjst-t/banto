banto で使う言葉は多くありません。この6つを知っていれば足ります。

## Project

仕事の入れ物です。1つの作業フォルダ（root）を持ち、同じ仕事が続くかぎり残ります。Project ごとにコンテナが1つ作られ、AI のコマンドやファイル操作はその中で行われます。

別のサーバを実行場所にすることもできます（たとえば仮想化の支援が要る仕事のために、物理サーバを使う場合）。

## Thread（会話）

1本の会話です。Project には主の会話（Base）が1本と、そこから枝分かれした会話（Fork）がいくつかあります。

## Fork

枝分かれした会話です。「同じ話の続き」ではなく、**同じ文脈から出た別の試み**を表します。たとえば、同じ依頼から3つの実装を試して比べるときや、本筋とは別の調べものを並行して進めるときに使います。

Fork を作るときは、それまでの会話を引き継ぐか、まっさらで始めるかを選べます。AI が自分で Fork を立てて仕事を分けることもあります。

## Memory

その Project で「決まったこと」の控えです。会話が長くなって畳まれても、Fork しても、Memory は残り、毎回 AI に渡されます。AI は設計判断などが決まったときに Memory へ書き足します。

## 受信箱

人の番になったものが集まる場所です。AI が承認を求めているもの、判断を求めているもの、お知らせが並びます。サイドバーでも、どの会話が動いていて（回る輪）、どれがあなたの答えを待っていて、どれにまだ読んでいない返事があるか（太字）が分かります。

## Module

banto に機能を足す部品です。コマンドの実行（Shell）、ファイル（FileSystem）、秘密の保管（Vault）など、よく使うものは最初から入っています。Module は **AI からも人からも使えます**——AI が開いた画面を人が続きから触れますし、人が見ている画面について AI に相談できます。

一覧は [Module](/docs/guide/modules/) を見てください。
