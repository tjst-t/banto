title: 基本概念
description: プロジェクト、会話、Fork、Memory、受信箱、モジュールについて。
---

banto を使ううえで知っておきたい概念は、次の6つです。

## プロジェクト

作業の単位です。作業ディレクトリ（ルート）を1つ持ちます。プロジェクトごとにコンテナが作成され、AI によるコマンドの実行やファイル操作はそのコンテナ内で行われます。

ハードウェア仮想化が必要な作業などのために、別のサーバーをプロジェクトの実行環境として指定することもできます。

## 会話（Thread）

AI とのやり取りの単位です。各プロジェクトには、メインの会話（Base）が1つと、そこから分岐した会話（Fork）が任意の数だけあります。

## Fork

会話の分岐です。単なる続きではなく、**同じ前提から始める別のアプローチ**として使います。たとえば、同じ依頼に対して3通りの実装を試して比較したいときや、本題とは別の調査を並行して進めたいときに便利です。

Fork を作成するときは、それまでの会話を引き継ぐか、新しい会話として始めるかを選べます。AI が作業を分担するために、自分で Fork を作成することもあります。

## Memory

プロジェクトで決定した事項の記録です。会話が長くなって要約されたあとも、Fork した先でも、Memory の内容は毎回 AI に渡されます。設計上の判断などが決まると、AI が Memory に追記します。

## 受信箱

対応が必要なものが集まる場所です。AI からの承認依頼や判断の依頼、各種の通知が表示されます。

サイドバーでも、AI が作業中の会話（回転するアイコン）、あなたの判断を待っている会話、未読の返信がある会話（太字）を確認できます。

## モジュール

banto に機能を追加するコンポーネントです。コマンドの実行（Shell）、ファイル操作（FileSystem）、シークレットの管理（Vault）など、よく使う機能は標準で組み込まれています。

モジュールは **AI と人の両方から利用できます**。AI が開いた画面を人がそのまま操作することも、人が見ている画面について AI に相談することもできます。

詳しくは [モジュール一覧](/docs/guide/modules/) を参照してください。
