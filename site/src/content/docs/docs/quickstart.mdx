このページでは、banto をインストールしてから、最初のプロジェクトで AI に作業を依頼し、Fork で別の案を試すまでの流れを紹介します。所要時間は15〜30分ほどです。

## 始める前に

次のものを用意してください。

- Ubuntu 24.04 または 26.04 のサーバー（仮想マシンでも可）と、sudo 権限のあるユーザー
- banto に割り当てるドメイン名（例：`banto.example.com`）
- Claude のアカウント

<Aside type="tip">
ドメインを Cloudflare で管理している場合は、API トークンを用意しておくと DNS レコードと証明書が自動で設定されます。作成方法は[インストール](/docs/install/#cloudflare-の-api-トークンを作成する)を参照してください。
</Aside>

## 1. インストールする

<Steps>

1. サーバーにログインし、次のコマンドを実行します。`banto.example.com` は、用意したドメイン名に置き換えてください。

   ```sh
   curl -fsSL https://banto.tjst-t.dev/install.sh | bash -s -- --domain banto.example.com
   ```

2. 途中で sudo のパスワードと Cloudflare の API トークンの入力を求められます。トークンがない場合は、何も入力せずに Enter キーを押してください。

3. 続けて Claude へのログインが始まります。表示される URL をブラウザで開き、ログインを完了します。

4. インストールが完了すると、アクセス先の URL とログイン用のリンクが表示されます。

</Steps>

## 2. ログインしてパスキーを登録する

<Steps>

1. 表示されたログイン用のリンクをブラウザで開きます。リンクの有効期限は10分で、1回だけ使用できます。

2. 「設定」→「ログイン」を開き、パスキーを登録します。以降は、このパスキーでログインします。

3. スマートフォンも使う場合は、同じ画面の「端末を追加」で QR コードを表示し、スマートフォンで読み取ります。

</Steps>

## 3. プロジェクトを作成する

<Steps>

1. サイドバーの「新しい Project」を選びます。

2. 作成方法を選びます。サーバー上にあるフォルダを使う場合は「手元のフォルダ」を選びます。GitHub のリポジトリをクローンして始めることもできます（先に [Repositories](/docs/modules/repositories/) で GitHub アカウントを登録しておきます）。

3. プロジェクトを作成すると、メインの会話（Base）が開きます。このプロジェクト用のコンテナが自動で作成され、AI の操作はその中で行われます。

</Steps>

## 4. AI に作業を依頼する

入力欄に依頼を書いて送信します。たとえば、次のように依頼してみてください。

```text
このリポジトリの構成を調べて、テストの実行方法を教えてください。
```

AI はファイルを読み、必要に応じてコマンドを実行します。コマンドの実行など確認が必要な操作では、会話の中に承認カードが表示されます。内容を確認して「許可」を選ぶと実行されます。

<Aside>
AI が作業している間、サイドバーの会話にはアイコンが回って表示されます。別の会話やプロジェクトに移動しても、作業は続きます。承認や判断が必要になったときや、作業が終わったときは、受信箱に表示されます。受信箱の中で答えたり、次の指示を返信したりできます。
</Aside>

## 5. Fork で別の案を試す

<Steps>

1. 会話のヘッダーにある「Fork を開く」を選びます。

2. 名前（例：「案B：ライブラリを使う」）を入力し、「会話を引き継ぐ」を選んで作成します。

3. Fork した会話で、別の方針を指示します。元の会話と Fork は並行して進み、サイドバーで両方の状態を確認できます。

</Steps>
