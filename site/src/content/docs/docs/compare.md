AI エージェントを使った開発ツールには、さまざまな種類があります。このページでは、banto がどのような場合に向いているか、どのような場合にほかのツールのほうが合うかを説明します。

:::note
ほかのツールの特徴は、2026年10月時点の一般的な使い方にもとづく大まかな整理です。各ツールの機能は頻繁に更新されるため、詳しくはそれぞれの公式ドキュメントを確認してください。
:::

## banto と Claude Code の関係

banto は Claude Code の代わりではありません。banto の会話の中では Claude Code（Claude Agent SDK）が動いており、依頼を理解して作業を進める部分は Claude Code が担います。コマンドの実行やファイル操作は、banto のモジュールを通じて、プロジェクトのコンテナの中で行われます。

banto が担うのは、その外側です。

- 複数のプロジェクトと会話をまとめて管理し、状態をひと目で見られるようにする
- 承認や判断の依頼を受信箱に集める
- プロジェクトごとのコンテナで AI の作業を隔離する
- シークレットの管理、開発サーバーの起動と公開、ブラウザ、バックログ、自動実装などのツールを用意する
- ブラウザやスマートフォンから、どこでも同じ状態を見られるようにする

Claude Code のアカウント（Claude のサブスクリプション）は、banto でもそのまま使います。

## 種類ごとの比較

| | ターミナル型<br />（Claude Code・Codex CLI など） | エディター型<br />（Cursor など） | クラウド型<br />（Web 版の Codex・Claude Code など） | banto |
|---|---|---|---|---|
| AI が作業する場所 | 手元のパソコン | 手元のパソコン | サービス提供元のクラウド | 自分のサーバーのコンテナ |
| 得意な使い方 | 1つの作業を対話しながら進める | コードを見ながら細かく手直しする | 依頼を投げて結果を受け取る | 複数の作業を並行させて、まとめて見守る |
| 複数の作業の並行 | ターミナルを複数開いて管理する | 製品によっては可能 | 可能 | プロジェクトと Fork で並行し、状態を一覧できる |
| 確認待ちの把握 | 各ターミナルを見て回る | エディター内で確認する | 各タスクの画面で確認する | 受信箱にまとめて集まる |
| 手元の端末を閉じたとき | 作業が止まる | 作業が止まる（クラウド実行を除く） | 続く | 続く |
| スマートフォンからの操作 | 製品の連携機能による | 難しい | 可能 | 可能 |
| 準備の手間 | 少ない | 少ない | ほぼ不要 | サーバーとドメインの用意が必要 |
| チームでの利用 | 可能 | 可能 | 可能 | 未対応（1人で使う前提） |

## banto が向いている場合

### 複数の作業やプロジェクトを、同時に AI に任せたい

ターミナルやウィンドウを行き来しながら、どの作業がどこまで進んだか、どれが確認を待っているかを追うのに疲れている場合に向いています。banto では、すべてのプロジェクトの確認待ちが受信箱に集まり、サイドバーで状態をひと目で把握できます。

### 自分のサーバーで動かしたい

コードや開発環境、会話の履歴を、自宅や社内のサーバーに置いておきたい場合に向いています。外部に送られるのは、AI との会話の内容（Claude の API）と、自分で設定した連携先への通信だけです。

### パソコンから離れても作業を進めたい

AI の作業はサーバー側で続くため、パソコンを閉じても止まりません。外出先のスマートフォンから、承認したり、進み具合を確認して次の指示を出したりできます。

### AI に安心して権限を渡したい

AI の作業はプロジェクトごとのコンテナに閉じ込められ、ほかのプロジェクトやサーバー本体には届きません。トークンや鍵は Vault で管理し、値を AI に見せずに渡せます。確認なしで作業させる設定にしても、影響はそのプロジェクトの中にとどまります。

### 開発の周辺作業までまとめて任せたい

開発サーバーの起動と公開、ブラウザでの表示の確認、バックログの管理、タスクの実装からマージまでの自動化（Factory）まで、banto の中で一続きに進められます。

## ほかのツールが合う場合

### 1つの作業を、エディターでコードを見ながら進めたい

コードの差分を細かく確認しながら、少しずつ手直ししていく使い方には、Cursor などのエディター型や、エディターに組み込む拡張機能が向いています。banto でもファイルの内容は確認できますが、エディターの代わりにはなりません。

### サーバーを用意せずに、すぐに試したい

banto を使うには、Ubuntu のサーバーとドメイン名を用意する必要があります。まずは AI エージェントを試してみたいという段階であれば、手元のパソコンで Claude Code や Codex を使うか、クラウド型のサービスを使うほうが手軽です。

### チームで使いたい

banto は現在、1人で使うことを前提にしています。複数人でのプロジェクトの共有、権限の管理、組織向けの管理機能には対応していません。

### 会話に Claude 以外のモデルを使いたい

banto の会話は Claude（Claude Code）だけに対応しています。OpenAI のモデルなど、ほかのモデルを中心に使いたい場合は、それぞれのモデルに対応したツールが向いています。なお、[サブエージェント](/docs/modules/subagent/)には OpenCode を使えるため、作業の一部をほかのモデルに任せることはできます。

### Mac や Windows の上で直接作業させたい

banto の AI は、Linux のコンテナの中で作業します。Xcode を使う iOS アプリの開発や、Windows のデスクトップアプリの操作など、特定の OS の上で直接作業させたい場合には、その OS で動くツールが向いています。

## 組み合わせて使う

banto とほかのツールは、組み合わせて使うこともできます。

- 並行して進める作業や長時間かかる作業は banto に任せ、細かい手直しは手元のエディターで行う
- banto のプロジェクトのリポジトリを手元にもクローンしておき、AI がコミットした内容を手元で確認する
