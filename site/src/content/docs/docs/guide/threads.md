## プロジェクトを作成する

サイドバーの「新しい Project」からプロジェクトを作成します。作成方法は次の3つから選べます。

- **既存のフォルダを使う**
- **GitHub のリポジトリをクローンする**
- **新しいリポジトリを作成する**

プロジェクトを作成すると、メインの会話（Base）が1つ作られます。

## Fork を作成する

Fork は、同じ前提から別のアプローチを試すための会話の分岐です。次の3つの方法で作成できます。

- 会話のヘッダーの **「Fork を開く」**：それまでの会話を引き継ぐか、新しい会話として始めるかを選べます。
- メッセージの下の **「ここから Fork」**：そのメッセージまでの会話を引き継いで分岐します。
- サイドバーの **「＋ 新しい Fork」**：新しい会話として作成します。

いずれの方法でも、作成時に名前を入力できます（省略すると連番になります）。AI が作業を分担するために、自分で Fork を作成することもあります。

不要になった Fork は閉じることができます。閉じた Fork は、サイドバー左下の履歴から再び開けます。

## サイドバーの表示

| 表示 | 意味 |
|---|---|
| 回転するアイコン | AI が作業中 |
| 太字の名前 | 未読の返信がある |
| 手のアイコン（オレンジ） | あなたの判断を待っている |
| 名前の下の補足 | バックグラウンドで実行中の処理（サブエージェントや時間のかかるコマンドなど）がある |

開いていないプロジェクトでも、その中の会話で AI が作業中であればプロジェクトのアイコンが回転し、未読の返信があればプロジェクト名が太字で表示されます。

## AI の処理を停止する

入力欄の停止ボタンで、AI の処理を停止できます。AI がまだ応答を書き始めていない段階で停止した場合は、送信したメッセージが取り消され、入力欄に戻ります。応答の途中で停止した場合は、それまでに出力された内容が残ります。

## スマートフォンで使う

スマートフォンのブラウザでも、そのまま利用できます。ホーム画面に追加すると、アプリのように起動できます。スマートフォンではキーボードの Enter キーで改行し、メッセージの送信には送信ボタンを使います。
