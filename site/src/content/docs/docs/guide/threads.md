## 会話する

入力欄に依頼を書いて送信します。パソコンでは Enter キーで送信、Shift + Enter キーで改行します。画像は入力欄に貼り付けて添付できます。

AI の作業はサーバー側で続くため、送信したあとは別の会話やプロジェクトに移動しても問題ありません。ブラウザを閉じても作業は止まりません。

### AI の処理を停止する

入力欄の停止ボタンで、AI の処理を停止できます。

- AI がまだ応答を書き始めていない段階で停止した場合は、送信したメッセージが取り消され、入力欄に戻ります
- 応答の途中で停止した場合は、それまでに出力された内容が残ります

### モデルと権限モード

入力欄の横で、使用するモデルと権限モードを会話ごとに切り替えられます。権限モードは、AI の操作をどこまで確認なしで実行させるかの設定です。詳しくは[受信箱と承認](/docs/guide/inbox/#権限モード)を参照してください。

## Fork を作成する

Fork は、同じ前提から別のアプローチを試すための会話の分岐です。次の方法で作成できます。

| 操作 | 作成される Fork |
|---|---|
| 会話のヘッダーの「Fork を開く」 | それまでの会話を引き継ぐか、新しく始めるかを選択 |
| メッセージの下の「ここから Fork」 | そのメッセージまでの会話を引き継ぐ |
| サイドバーの「＋ 新しい Fork」 | 新しい会話として作成 |
| 会話のメニューの「ここから Fork…」 | その会話の最新の状態を引き継ぐ |

いずれの方法でも、作成時に名前を入力できます（省略すると連番になります）。Fork からさらに Fork を作成することもできます。

### AI が Fork を作成する場合

複数の独立した作業がある場合、AI が自分で Fork を作成して作業を分担することがあります。作成された Fork は、名前と最初の指示を受け取って自動で作業を始めます。

### Fork を閉じる

不要になった Fork は閉じることができます。バックグラウンドで実行中の処理が残っている場合は、閉じる前に警告が表示されます。閉じた Fork は、サイドバー左下の履歴から再び開けます。

## サイドバーの表示

| 表示 | 意味 |
|---|---|
| 回転するアイコン | AI が作業中（承認や判断を待っている間も含む） |
| 太字の名前 | 未読の返信がある |
| 名前の下の補足 | バックグラウンドで実行中の処理がある（サブエージェントや時間のかかるコマンドなど）。選択すると一覧が開く |

開いていないプロジェクトでも、その中の会話で AI が作業中であればプロジェクトのアイコンが回転し、未読の返信があればプロジェクト名が太字で表示されます。

プロジェクト名を選ぶと、そのプロジェクトで最後に開いていた会話が開きます。

## 会話の終わりのまとめ

プロジェクトの設定の「一般」→「会話」で「ターンの終わりにまとめを出す」を有効にすると、AI は作業のあとに「依頼内容・結果・分かったこと・確認していないこと・あなたに決めてほしいこと」をまとめたカードを表示します。決めてほしいことには回答の候補が付き、選ぶと入力欄に入ります。

まとめは[受信箱](/docs/guide/inbox/)のカードにも表示されるため、会話を開かずに結果を確認し、そのまま返信できます。決めてほしいことがある会話は、受信箱の上のほうに表示されます。
