---
title: 会話と Fork
description: 会話を枝分かれさせて、同じ文脈から別の試みを並べる。
---

## Project を作る

サイドバーの「新しい Project」から作ります。始め方は3つです。

- **手元のフォルダを選ぶ**
- **GitHub から clone する**
- **新しいリポジトリを作る**

作った Project には主の会話（Base）が1本できます。

## Fork を作る

Fork は、同じ文脈から出た別の試みです。作り方は3つあります。

- 会話のヘッダの **Fork を開く**：会話を引き継ぐか、まっさらで始めるかを選べます。
- 発言の下の **ここから Fork**：その発言までの会話を引き継いで分けます。
- サイドバーの **＋ 新しい Fork**：まっさらな Fork を作ります。

どれも名前を聞かれます（空なら連番になります）。AI が仕事を分けるために自分で Fork を立てることもあります。

Fork が要らなくなったら閉じます。閉じた Fork は左下の履歴から開き直せます。

## サイドバーの印

| 印 | 意味 |
|---|---|
| 回る輪 | AI が動いている |
| 名前が太字 | AI が返したあと、まだ開いていない |
| 手のアイコン（朱色） | あなたの答えを待っている |
| 名前の下の薄い1行 | 裏で走っている仕事（サブエージェント・長いコマンドなど） |

いま開いていない Project でも、中のどれかの会話が動いていれば Project の頭文字が回り、未読があれば Project 名が太字になります。

## 止める

入力欄の停止ボタンで AI のターンを止めます。AI がまだ何も書いていないうちに止めたら、送った発言を取り消して入力欄へ戻します。書き始めてから止めたものは、出た分を残します。

## 携帯で使う

携帯のブラウザでもそのまま使えます。ホーム画面に追加すればアプリのように開けます。携帯ではキーボードの Enter は改行で、送るのは送信ボタンです。
