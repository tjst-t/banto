## 受信箱

人の番になったものが集まります。

- **判断待ち**：AI が承認や選択を求めているもの
- **レビュー待ち**：AI が返したあと、まだ見ていない会話
- **お知らせ**：資源の上限に当たった、ログインが切れた、など

並んだものを押すと、その会話のその場所が開きます。

## 承認

AI が Module を使うとき、操作によっては人の承認を求めます。承認は会話の中にカードで出て、選択肢を押せばそのまま答えが送られます。

会話ごとの承認の扱い（毎回聞くか、どこまで任せるか）は、入力欄の隣で切り替えます。

### 承認をすべて自動で許可する

Project の設定「一般」の「承認」でオンにすると、その Project の承認を全部自動で通します。自動で通したものも、会話には「自動で許可しました」の形で残ります。オフにすれば、また聞くようになります。

パスキーでの本人確認と、人が値を入れるもの（秘密の登録・ログイン）は、このスイッチがオンでも自動にはなりません。
