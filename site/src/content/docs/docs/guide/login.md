---
title: ログインと端末の管理
description: パスキーによるログイン、端末の追加と削除。
---

banto のログインには、パスワードを使いません。パスキーと、ログイン済みの端末から発行するリンクでログインします。

## パスキーを登録する

「設定」→「ログイン」でパスキーを登録します。パスキーは端末ごとに登録してください。認証の方法（指紋・顔認証・PIN など）は端末の設定に従います。

## 端末を追加する

ログイン済みの端末で「設定」→「ログイン」→「端末を追加」を選ぶと、QR コードとリンクが表示されます。追加したい端末で読み取るか、リンクを開くとログインできます。

- 有効期限は10分で、1回だけ使用できます
- 使用されると、発行した端末に通知されます
- 端末を追加する前に、パスキーによる本人確認が求められます

## ログイン中の端末を管理する

「設定」→「ログイン」に、ログイン中の端末が一覧表示されます。紛失した端末などは、ここから個別にログアウトさせられます。

ログインの有効期間は30日で、使用している間は延長されます。

## すべての端末でログインできなくなった場合

banto を動かしているユーザーでサーバーにログインし、次のコマンドを実行すると、ログイン用のリンクが発行されます（有効期限は10分）。

```sh
cd ~/.local/share/banto-release/current/banto && node scripts/login-link.mjs
```

## 公開したサービスへのアクセス

[Publish](/docs/modules/service/) で公開したサービスにアクセスするときも、banto のログインが使われます。banto にログインしているブラウザであれば、そのまま開けます。
