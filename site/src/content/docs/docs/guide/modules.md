title: モジュール一覧
description: banto に標準で組み込まれているモジュール。
---

モジュールは、AI と人の両方から利用できるコンポーネントです。AI はツールとして呼び出し、人は画面（Canvas）で操作します。

## 作業

| モジュール | 機能 |
|---|---|
| **Shell** | コンテナ内でコマンドを実行します。時間のかかるコマンドはバックグラウンドで実行し、終了時に AI に通知します |
| **FileSystem** | ファイルの読み書きと、ファイルの内容の表示 |
| **Terminal** | 人が操作するターミナル。画面を閉じても、セッションは維持されます |
| **Browser** | コンテナ内で動作するブラウザ。AI が操作している画面を、人も確認・操作できます |
| **Subagent** | 別の AI エージェント（Claude Code、OpenCode）に作業を依頼します |

## サービスの実行と公開

| モジュール | 機能 |
|---|---|
| **Service** | 開発サーバーなど、常駐させるプロセスを管理します。異常終了した場合は自動で再起動します |
| **Publish** | Service で起動したサーバーを、`<名前>.<banto のドメイン名>` で公開します。アクセスには banto へのログインが必要です |

## シークレット管理

| モジュール | 機能 |
|---|---|
| **Vault** | API トークンや SSH 鍵などを保管します。AI には参照名だけを渡し、値が AI のコンテキストに含まれることはありません |

## 開発フロー

| モジュール | 機能 |
|---|---|
| **Repositories** | リポジトリの一覧を管理します。GitHub からのクローン、新規作成、プロジェクトの作成ができます |
| **Backlog** | ストーリー、タスク、バグを管理します。データはリポジトリの専用ブランチに保存されます |
| **Factory** | Backlog のタスクについて、worktree の作成、実装、テスト、レビュー、main へのマージまでを自動で実行します |
