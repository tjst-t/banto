## プロジェクトを作成する

サイドバーの「新しい Project」から作成します。作成方法は次の3つです。

| 作成方法 | 内容 |
|---|---|
| 手元のフォルダを使う | サーバー上の既存のフォルダを、そのままプロジェクトのルートにします |
| GitHub からクローンする | GitHub のリポジトリをクローンし、そのフォルダをルートにします |
| 新しいリポジトリを作る | 新しいフォルダを作って `git init` し、ルートにします |

GitHub からのクローンや新規作成には、[Repositories](/docs/modules/repositories/) に GitHub アカウントを登録しておく必要があります。クローン先の既定の場所は `~/banto/<リポジトリ名>` です。

プロジェクトを作成すると、そのプロジェクト用のコンテナが作られ、メインの会話（Base）が開きます。

:::note
プロジェクトのルートには、作業に必要な範囲のフォルダを指定してください。ホームディレクトリ全体のような広いフォルダを指定すると、AI がそのすべてを読み書きできるようになるため、警告が表示されます。
:::

## AI への指示

プロジェクトの設定の「一般」にある「AI への指示」に、そのプロジェクトで AI に常に守ってほしいことを書いておけます。

```text
- コミットメッセージは日本語で書く
- テストは npm test で実行する
- main ブランチに直接コミットしない
```

指示を書き換えると、そのプロジェクトのすべての会話で、次の応答から反映されます。

## Memory

プロジェクトで決まった事項は、AI が Memory に記録します。Memory の内容は、会話が長くなって要約されたあとも、Fork した先でも、毎回 AI に渡されます。

- AI に「この方針で決定。Memory に残して」と伝えると、決定事項として記録されます
- 内容はプロジェクトの設定の「Memory」で確認・編集できます
- すべてのプロジェクトに共通する事項（例：「回答は日本語で」）は、banto 全体の設定の「Memory」に書きます

「AI への指示」は人が書くルール、Memory は作業の中で決まった事項の記録、という使い分けをおすすめします。

## プロジェクトの設定

サイドバーのプロジェクト名のメニュー、または画面右上の設定から開きます。

| 項目 | 内容 |
|---|---|
| 一般 | プロジェクト名、AI への指示、承認の自動許可、実行環境 |
| Memory | このプロジェクトの決定事項の確認と編集 |
| Module | このプロジェクトで使うモジュールの追加・削除・設定 |
| Skill | このプロジェクトで使う Skill（作業手順書） |
| コンテナ | メモリ・CPU・プロセス数の上限（banto 全体の上限より下げる場合） |
| セキュリティ境界 | コンテナに渡すもの・渡さないものの確認 |

## プロジェクトを閉じる

使わなくなったプロジェクトは、プロジェクト名のメニューから閉じることができます。閉じてもプロジェクトのフォルダは削除されません。閉じたプロジェクトは、サイドバー左下の履歴から再び開けます。
