---
title: 別のサーバーで実行する
description: SSH で接続した別のサーバーを、プロジェクトの実行環境にする。
---

プロジェクトは通常、banto をインストールしたサーバー上のコンテナで動作します。次のような場合は、SSH で接続した別のサーバーをプロジェクトの実行環境（実行場所）にできます。

- 仮想マシンやハードウェア仮想化を使う作業（Proxmox や containerlab の検証など）を、物理サーバーで行いたい
- banto のサーバーより大きなメモリや CPU が必要
- 特定のハードウェアや環境があるサーバーで作業したい

## 実行場所を登録する

banto 全体の設定の「実行場所」から登録します。

1. 接続先のホスト名・ユーザー名・ポートと、接続に使う SSH 鍵（[Vault](/docs/modules/vault/) に登録したもの）を指定します
2. 接続して、表示されたホスト鍵のフィンガープリントを確認します
3. 必要なツールがそろっているかの確認が行われます。不足しているものがあれば表示されます
4. 問題がなければ登録します

接続先のサーバーには、git・ssh・curl・tar が必要です。banto のプログラムは、banto が SSH 経由で自動的に転送します。接続先に専用のユーザーを作成することをおすすめします。

## プロジェクトで使う

新しいプロジェクトを作成するときに、最初に実行場所を選びます。接続先のサーバー上のフォルダが、プロジェクトのルートになります。

1つの実行場所に置けるプロジェクトは1つだけです。

## プロジェクトを別の実行場所に移す

既存のプロジェクトは、プロジェクトの設定の「一般」から別の実行場所に移せます。プロジェクトのフォルダ（`.git` を含む）とモジュールのデータがコピーされ、会話の履歴と Memory はそのまま引き継がれます。

- 動作中の Service や実行中の処理がある場合は、移動できません
- 移動元のフォルダは削除されずに残ります
- インストールしたツールや Docker のイメージなど、フォルダの外にあるものは移動されません

以前いた実行場所に戻す場合は、差分だけがコピーされます。
