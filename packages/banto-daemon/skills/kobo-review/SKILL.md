# 判断待ちを捌く

## いつ使うか

**工場から「レビュー待ちです」が会話に届いたとき。** その札には、経緯・起きたこと・求める判断が
書いてある。あなたが一次受けで、**捌けたら通す・捌けなければ取次へ上げる**（決定57）。

放っておくと、工場は判断待ちで詰まる。ready のタスクは動き続けるが、**通っていないものは
マージされない**——`kobo.list` に `review-ready` が溜まっていたら、それはあなたの番。

## 手順

1. **`kobo.task` で中身を読む。** 状態・レビューの段・変更の範囲・受け入れ基準・監査の判定、
   そして**触れる場所**（あれば）が返る
2. **`po` と出ていたら、あなたは通せない。** 3へ飛ぶ
3. **確かめる。** 何を確かめるかは、そのタスクが何を変えたかで決まる：
   - 受け入れ基準に検証コマンドがあるなら、**それは既に機械が回している**（監査＋マージ前ゲート）。
     あなたが同じことをやり直す必要はない
   - **触れる場所（URL）があるなら開く。** UI を変えたタスクは、通す前に自分で触る
   - diff を読みたいなら `git.*`（キャンバスの DIFF 面でもよい）
   - **報告や監査の「通った」を鵜呑みにしない**（I1）。ただし**疑うために何度も職人を起こさない**
     ——2つの機械的検査（別セッションの監査・マージ前ゲート）の上に、あなたの判断が乗る形になっている
4. **通す**：`kobo.approve`（`note` に**何を見て良しとしたか**を書く。帳簿に残る）
   - **通しても関所は飛ばない。** この後マージ前ゲート（スコープ違反の検査と検証コマンド）が
     回り、あなたに飛ばす手段は無い（決定57）
5. **捌けなければ取次へ上げる**（下記）

## 取次へ上げる（POの判断が要るとき）

**上げるのは3つのときだけ**（D9）。それ以外は自分で決めて進める。

| 上げる | 例 |
|---|---|
| **D1**：不可逆な選択 | 公開I/F・データモデル・外部依存の追加・外に出ていく操作 |
| **D9**：利用体験を変え、**かつ**本物のトレードオフがある | 画面の主従・言葉遣いの方針・速さと正しさの取り合い |
| **P3**：仕様と実態が食い違っている | spec と違う実装になっているが、どちらが正しいか決められない |
| **決定57**：`kobo.task` が `po` と返した | 統治コード（`governance: true`）／PO 必須の面に触る |

`inbox.post` に渡すもの——**札だけで判断できること**が要件（`spec-ui` §3）：

```
sourceId:    "kobo"
sourceLabel: "工場（<プロジェクト名>）"
kind:        "番頭では決められない"          # 種別の表示名
rule:        "決定57"                        # よりどころ（D1 / D9 / P3 / 決定57）
title:       一行で言う問い
why:         経緯——**元になったPOの指示を引用する**（kobo.task の originRef がそれ）
what:        起きたこと——実装され、監査を通り、いま何が待っているか
ask:         求める判断——POに決めてほしいことと、判断の材料
actions:     押せる答えを2〜4つ（「通す」「差し戻す」「保留」など）
canvasKind:  "kobo.review"                   # 押すと会話と面が同時に開く
canvasParams: { projectTag, taskId }
```

- **`why` を省かない。** 工場は経緯を知らないので、あなたが積むときに渡した `originRef` が
  唯一の出どころ。ここが空だと、PO は「起きたこと」しか読めない札を受け取る（D8）
- **触れる場所があるなら `what` に URL を書く。** 「見て決めて」ではなく「触って決めて」にする（決定59）
- 積んだら**その件は進めない**。POが答えるまで待つ

## 気をつけること

- **`po` のタスクを通そうとしない。** Tool が拒みますが、拒まれてから気づくのではなく、
  先に `kobo.task` で段を見ること
- **通した後は関所の結果を見る。** マージ前ゲートで落ちると `failed` になり、会話へ知らせが来る
  ——「通したから終わり」ではない
- **判断が付くと触れる環境は畳まれる**（決定59）。触るなら通す前に
