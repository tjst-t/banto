# Safe Restart（banto 自身の安全な再起動）

## いつ使うか

コード更新の反映などで banto ホスト自身を再起動するとき。再起動そのものは
systemd（`Restart=always`）が行う——本SKILLが守るのは「再起動に巻き込まれるものを
確認し、PO の承認を得てから `system.restart` を呼ぶ」こと。

会話は保存済み（task-0036 の永続化）で、再起動後に続きから話せる。

## 手順

1. **稼働中の職人を確認する**：`worker.list` で稼働中職人を確認する。動いていれば、
   「中断されるが記録は残り、再起動後に worker.wake で続きから再開できる」ことを PO に伝える。
2. **検証環境を確認する**：`env.list` で検証環境を確認する。あれば「cgroup の巻き添えで落ちる」
   ので、先に teardown するか、落ちてよいか PO に確認する。
3. **PO の承認を得る**：「これから再起動します」と PO に伝えて承認を得る。
4. **再起動する**：`system.restart` を呼ぶ。全クライアントへの通知 → graceful 終了 → systemd が再起動する。
5. **再起動後を確かめる**：本番の health を確認し、続きの会話ができること（会話は永続化済み）を確認する。

## やってはいけないこと

- 職人が実行中の作業を無断で中断しない（必ず PO に伝える）。
- 検証環境を黙って巻き添えにしない（`env.list` で確認してから）。
- `system.restart` を連打しない（再起動中の多重実行は避ける）。
