# 幹と枝と帳場

## いつ使うか

- いま話していることを、**このまま続けるか・枝にするか・別の幹にするか**で迷ったとき
- 枝を**畳んでよいか**、何を結論として書くかで迷ったとき
- 帳場で受けた話を**どこへ流すか**決めるとき
- 幹を**終うとき**（持って出る記憶の選び方）

## 3つの場所

| | 何か | 寿命 |
|---|---|---|
| **帳場** | どの幹の話でもないものの受け皿。店にただ1つ | **終えない** |
| **幹** | 1つのプロジェクト。決めたことの帯 | プロジェクトが終わるまで |
| **枝** | 終わりのある1つの問い | 還す条件を満たすまで |

## 判定は2問。軸が違うので混ぜない

**問1「新しい記憶の区画が要るか」→ 幹を起こすか**

> **その記憶を、いまの幹の会話に混ぜたいか。**

混ぜたいなら同じ幹。混ぜると雑音になるなら別の幹（`thread.open_trunk`）。
言い換えると「**前にこの話をした、と思い出してほしい相手が同じか**」。

- 「banto の systemd の話」と「banto の UI 再設計」→ 同じ記憶が効く → **同じ幹**
- 「loamium のエディタUI」と「banto の UI」→ 見かけは似ているが、loamium の事情を
  banto の判断に混ぜたくない → **別の幹**
- 「本を探す」のような一回きりの用事 → 溜めたい記憶が無い → **幹にしない**（帳場で片付ける）

**問2「往復が続くか」→ 枝にするか**（同じ幹の中と決めたあと）

> **何が決まれば幹に還るかを、いま書けるか。**

書けるなら枝（`thread.open`）。書けないならそのまま幹で話す。

この2問は独立している。問1で「同じ幹」と決めた話が、問2で枝にも幹の中の会話にもなる。

## 枝を開くとき

```
thread.open({
  title: "間欠的に落ちる試験",
  returnCondition: "再現条件が特定できたら",   // 何が決まれば還るか
  reason: "往復が続くので幹が読めなくなる",     // なぜ幹ではなくここか
  message: "…",                                // 枝へ渡す最初の一言（任意）
})
```

- **枝の中で枝は開けない。** 別の問いが要るなら、この枝を畳んで幹へ還してから開き直す
- 開いた瞬間に**幹へ札が1行**立つ。これがあるから枝は埋没しない
- 枝の中身は幹に流さない。幹に載るのは**開いた1行と還った1行だけ**

## 枝を畳むとき

**出口は「結論」であって「実装」ではない。** incident を起票し task を積んだ時点で畳む
——実装の寿命まで開いておくと、開いている枝の一覧が信用できなくなる。

```
thread.merge({ conclusion: "inc-0048 を起票し task-0091 を積んだ" })
```

- **保留も結論の一種。**「保留：計測が足りない」で畳んでよい。開き直せる
- 「幹で話せば足りる話でした」も立派な結論
- 幹に残るのはこの1行だけなので、**何が決まったかを言い切る**

畳んだ枝では**もう話せない**。続きが要るなら履歴から開き直す。

## 帳場で受けた話をどう流すか

帳場は**プロジェクトではない**。banto 開発の幹でもない。ここへ来るのは:

- 宛先の決まらない知らせ（孤児の検証環境・出所が会話に紐づかない報告）
- まだプロジェクトになっていない相談
- 一回きりの用事

流し方:

1. **その場で片付く** → 帳場で答えて終わり。記憶に残す値打ちがあれば `memory.save`
2. **既にある幹の話だった** → そう言って、その幹へ移ってもらう（勝手に幹を増やさない）
3. **新しい仕事になった** → `thread.open_trunk` で幹を起こし、そちらで続ける

## 幹を終うとき

プロジェクトが終わったら `thread.close_trunk`。**開いている枝があると終えられない**ので、
先に畳む（終うと枝が札ごと履歴へ沈み、埋没する）。

```
thread.close_trunk({ threadId: "thread-51", carry: ["…", "…"] })
```

**`carry` があなたの判断。** 枝の結論が幹へ還るのと同じ形が、一段上で繰り返される。

- **その幹でしか通じない事情は置いていく**（「この案件では〜」「このリポジトリの〜」）
- **他の仕事でも効く一般解だけを持って出す。** 持って出るときは**書き直す**
  ——「loamium では incus を使った」ではなく「ブラウザを隔離して動かすなら incus＋Xvfb が要る」
- 持って出るものが無ければ空の配列でよい。無理に絞り出さない（I1）

帳場は終えられない。
